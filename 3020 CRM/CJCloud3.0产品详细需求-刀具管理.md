# 🔮 概述

## 1、 用户故事

**用户故事 1：刀具库存管理**   作为一名刀具管理人员，我希望能够实时查看刀具的库存状态，以便在库存低于预设水平时及时补充，避免因刀具短缺而导致的生产停滞。

**用户故事 2：刀具使用跟踪**   作为一名刀具管理人员，我希望能够跟踪每把刀具的使用寿命和维护记录，以便在刀具即将达到使用寿命时安排维护或更换，确保生产的连续性和产品质量。

**用户故事 3：刀具寿命预测**   作为一名刀具管理人员，我希望能够预测刀具的剩余使用寿命，以便提前安排更换，减少因刀具损耗导致的停机时间。

**用户故事 4：刀具历史使用记录**   作为一名刀具管理人员，我希望能够查看每把刀具的详细历史使用记录，以便分析其表现和确定最佳使用条件。

**用户故事 5：刀具故障报告**   作为一名刀具管理人员，我希望能够快速记录和报告刀具故障，以便分析原因和采取纠正措施，减少类似问题的再次发生。

**用户故事 6：刀具使用效率报告**   作为一名刀具管理人员，我希望能够生成刀具使用效率报告，以便识别低效使用的刀具和优化加工流程。

**用户故事 7：刀具自动化补货**   作为一名刀具管理人员，我希望能够实现刀具的自动化补货流程，以减少人工干预和避免库存不足。

**用户故事 8：刀具损耗监控**   作为一名刀具管理人员，我希望能够实时监控刀具的损耗情况，以便及时采取措施，延长刀具使用寿命。

这些用户故事涵盖了刀具管理的核心需求，确保了刀具的有效管理和使用，从而支持生产的高效运行。

## 4、公共规则

- 凡是人工录入的条件查询，皆为模糊查询
- 凡是表格，皆有排序、皆带合计
- 凡是数字，皆有千分位符，皆靠右显示
- 凡是文字，皆靠左显示
- 凡是时间，皆为yyyy-MM-dd hh:mm:ss，日期，皆为yyyy-MM-dd
- 凡是单据展示，皆有左树快捷查询
- 凡是业务按钮，皆为权限按钮
- 凡是业务单据，有主子表结构的都有（全部，列表，与我相关）

- 凡是手机端，平板端状态查询的，为页签平铺且全部在最后

**【功能描述】** 刀具采购计划功能帮助企业根据生产需求和库存状况制定科学的采购策略。通过需求预测、库存管理和采购周期安排，企业能够确保刀具的充足供应，避免生产停滞。这一功能的优化能够有效控制采购成本，提高采购效率。

**【功能说明】**

- **业务菜单**：刀具管理 -> 采购管理 -> 刀具采购计划
- **业务按钮**：
    - 创建采购计划：输入预测需求和库存数据，生成采购计划。
    - 查看历史计划：查询和分析以往的采购计划。
    - 导出采购计划：导出计划详情，供采购部门参考。
- **单据来源**：生产计划、库存数据。
- **单据去向**：生成采购订单。

**【处理流程及业务规则、算法描述】**

【处理流程及业务规则、算法描述】

- **审批流**：
    - 请购单创建，单据状态默认'开立'
    - 提交至相关部门进行审批，通过后单据状态更新为'待采购'；如果被驳回，则单据状态更新为'已取消'
    - 审批通过的请购单支持采购订单拉取生单，单行支持多次生单，当累计采购数量小于请购量，行状态更新为'采购中'，累计采购数量等于请购量时，行状态更新为'已完成'
- **税务计算**：
    - 根据税率和税目自动计算税额，并更新含税和无税金额。
- **汇率转换（预留功能）**：
    - 涉及外币交易时，根据设定的汇率进行金额转换，确保财务记录准确。

**【处理流程及业务规则、算法描述】**

- **拉单新增**
    
    - 拉取的请购单必是同一个供应商，选供应商则过滤状态是审批通过，待采购或采购中的请购行；如果没选供应商，则当选择请购行后自动回写。
    - 拉取符合条件的请购行，按需求日期正序排序，需求日期小于当前日期的数据使用颜色额外标记。
    - 同一行请购明细，可以在一单中多次选择，但是必须将需求日期调整为不相同，否则提示。
    - 字段对应，选择请购单明细后，可以对应上的字段都带到采购订单上。
    
     
- **审批流**：
    - 采购订单创建后，单据状态默认’开立‘，提交至相关部门进行审批，审批通过后单据状态更新为’待确认‘或’待收货‘。
    - 采购订单创建，单据状态默认'开立'
    - 提交至相关部门进行审批，通过后单据状态更新为'待确认'‘或’待收货‘；如果被驳回，则单据状态更新为'已取消'
    - 审批通过的采购订单支持采购收货单拉取生单，单行支持多次生单，当累计收货数量小于采购量，行状态更新为'收货中'，累计收货数量大于或等于采购量时，行状态更新为'收货完成'。
- **关闭&打开**
    - 订单关闭后，不能发生业务，例如：拉单新增时无法选择到关闭的订单，且收货确认或入库确认时，需要提示订单已关闭，不允许操作。
