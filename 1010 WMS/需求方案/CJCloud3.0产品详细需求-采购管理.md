## 1、 用户故事

作为一个原材料仓库管理员角色，当我在做采购收货工作任务的时候，我希望使用手持PAD，以便于帮助我能够快速清点物流送达的原材料，否则只能通过手工记录的方式解决；

用户反馈

- 当原材料全部破损或者根本没有送达的情况，无法从系统体现。
- 购买了ERP的质检模块，但是希望使用CJC的采购模块管理原材料。
- 供应商提前先做过一次质检，希望让供应商能提前先填入，然后质检员看到供应商的质检结果再质检。
- 收货时不称量，不知道实际的原料重量，上架时会称量，但此时发现称量的重量，有时比收货重量少，有时多。
- 大批量来料时，来不及质检的会设置先入库，冻结库存，发起质检，合格后再释放库存为可用。

## 4、公共规则

- 双单位：采购管理的主单位取料品档案的采购单位，辅单位取料品档案的成本单位，录入主单位后使用采购-成本转换率自动计算辅数量。
- 凡是人工录入的条件查询，皆为模糊查询
- 凡是表格，皆有排序、皆带合计
- 凡是数字，皆有千分位符，皆靠右显示
- 凡是文字，皆靠左显示
- 凡是时间，皆为yyyy-MM-dd hh:mm:ss，日期，皆为yyyy-MM-dd
- 凡是单据展示，皆有左树快捷查询
- 凡是业务按钮，皆为权限按钮
- 凡是业务单据，有主子表结构的都有（全部，列表，与我相关）

    2.  部分报检数量合格，部分不合格，U9制作不合格处理报告，录入处理方案，审核不合格处理报表调用CJC接口，质检结果、质检单号、质检时间、合格数量、不合格数量、处理方式
2.  不合格处理（3.3.0）交期：**7月5号**测试完毕更新凯世通测试环境
    1.  单行质检（提供给U9接口文档）
        1.  全部报检数量合格时，调用cjc收货单质检完成接口，传入IMSlinekey、收货结论、质检结论、不合格处理类型qmcode、合格数量、不合格数量、退补数量、退扣数量、破坏数量
        2.  部分报检数量合格，部分不合格，U9在审核不合格处理报告时会拆分收货明细行，并且不合格处理报告中不同的质检结果会合并到收货单行上，例如：退货+补料+不合格同时存在时，会合并成一行收货单，破坏+报废同时存在会合并。至此，审核不合格处理报告时调用cjc收货单质检完成接口，传入IMSlinekey、收货结论、质检结论、不合格处理类型qmcode、合格数量、不合格数量、退补数量、退扣数量、破坏数量，cjc也进行拆好保存数据。
    2.  质检完成
        1.  回写订单：质检结论补料、不合格、破坏回写采购订单累计收货数量、剩余收货数量，允许继续送货。
        2.  自动生成待确认的采购质检退货单：质检结补料或退货时，自动生成采购质检退货单，并将收货单的退补数量、退扣数量、退货数量带到采购质检退货单。
    3.  取消质检
        1.  U9在弃审不合格处理报告时：调用cjc收货单取消质检接口，传入原行IMSLinekey，cjc判定有没有已经生成的入库单，如果有则提示存在后续单据无法弃审，请处理后在操作。
    4.  采购入库单，确认入库
        1.  按CJC不合格处理方式档案中，是否”允许入库“控制入库
        2.  U9收货单的质检结论是降级接收，让步接收，不合格接收，合格返修，写入库存的存储类型是【可用】
        3.  不合格接收，写入库存的存储类型是【不合格】
        4.  报废，写入库存的存储类型是【报废】
