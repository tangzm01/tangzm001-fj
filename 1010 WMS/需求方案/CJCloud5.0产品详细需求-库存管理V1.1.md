## 4、公共规则

- 双单位：采购管理的主单位取料品档案的采购单位，辅单位取料品档案的成本单位，录入主单位后使用采购-成本转换率自动计算辅数量，数量录入需要考虑单位精度。
- 凡是人工录入的条件查询，皆为模糊查询
- 凡是表格，皆有排序、皆带合计
- 凡是数字，皆有千分位符，皆靠右显示
- 凡是文字，皆靠左显示
- 凡是时间，皆为yyyy-MM-dd hh:mm:ss，日期，皆为yyyy-MM-dd
- 凡是单据展示，皆有左树快捷查询
- 凡是业务按钮，皆为权限按钮
- 凡是业务单据，有主子表结构的都有（全部，列表，与我相关）

# 💣基础数据

## 1、拣货规则

**【功能描述】**   拣货规则用于定义如何从仓库中选择物料，以便于高效准确地完成订单拣货。规则应考虑物料的位置、优先级、批次等因素。

**【功能说明】**

- 业务菜单：仓库管理 -> 拣货管理 -> 拣货规则
- 业务按钮：
    - 新增规则：创建新的拣货规则。
    - 编辑规则：修改现有的拣货规则。
    - 删除规则：删除不再使用的拣货规则。
    - 查询规则：根据条件查询拣货规则信息。
- 基础数据来源：
    - 由仓库管理人员根据仓库布局和业务需求手工建立。
- 基础数据用途：
    - 用于指导仓库拣货员高效准确地进行物料拣选。

**【关键数据项】**   字段名称|字段类型|字段长度|是否必填|默认值规则|联动逻辑|拣货规则编码

**【用户界面、交互及输入描述】**

- 以规则列表为默认视图，支持根据条件进行查询和筛选。
- 新增或编辑界面中，支持定义规则名称、优先级、适用范围等信息。
- 拣货规则查看界面，支持规则的批量操作和单行操作。
- 新增界面设置为两列，包含基本信息和适用条件。

**【处理流程及业务规则、算法描述】**

- 规则编码手动录入或自动生成，编码在系统内唯一。
- 规则启用后，修改需生成新版本的数据，记录版本信息。
- 支持按仓库或物料类别定义不同的拣货规则。

## 2、理货规则

**【功能说明】**

- 业务菜单：仓库管理 -> 理货管理 -> 理货规则
- 业务按钮：

    - 编辑规则：修改现有的理货规则。
    - 删除规则：删除不再使用的理货规则。
    - 查询规则：根据条件查询理货规则信息。
- 基础数据来源：
    - 由仓库管理人员根据仓库布局和业务需求手工建立。
- 基础数据用途：

**【关键数据项】**   字段名称|字段类型|字段长度|是否必填|默认值规则|联动逻辑|理货规则编码

**【用户界面、交互及输入描述】**

- 以规则列表为默认视图，支持根据条件进行查询和筛选。

- 新增界面设置为两列，包含基本信息和适用条件。

**【处理流程及业务规则、算法描述】**

- 支持按仓库区域或物料类别定义不同的理货规则。

# 📙 单据

## 1、调拨申请

### 【功能描述】

调拨申请用于记录和管理物料在不同仓库或地点之间的调拨需求，确保物料在需要的地方得到及时补充。

### 【功能说明】

- 业务菜单：仓库管理 -> 调拨管理 -> 调拨申请
- 业务按钮：
    - 整单新增调拨申请单：创建新的调拨申请单。
    - 依据生产备料做调拨申请：根据生产备料生成调拨申请单。
    - 整单修改调拨申请单：修改现有的调拨申请单。
    - 整单删除&批量删除：删除不再需要的调拨申请单。
    - 单据打印：打印调拨申请单。
    - 导出：将调拨申请单信息导出为文件。
    - 默认方案：设置或应用调拨申请单的默认方案。
    - 一键拣货：自动为调拨申请单生成拣货任务。
    - 分批调出：支持根据物料或数量分批生成调出单。
    - 数据同步：将其他系统的单据同步到调拨申请单。
    - 审批流及消息提示：提交调拨申请单进行审批，并在审批和操作过程中提供实时消息提示。
    - 关闭&打开单据：关闭当前调拨申请单，禁止进一步操作；重新打开已关闭的调拨申请单，允许编辑。
- 业务数据来源：
    - 由业务部门根据实际需求手工录入。
- 业务数据用途：
    - 用于规划和执行仓库间的物料调拨。

## 2、调出

**【功能描述】**   调出用于记录和管理物料从一个仓库调出到另一个仓库的实际操作，确保调拨过程的透明和可追溯。

**【功能说明】**

- \*\*业务菜单：\*\*仓库管理 -> 调拨管理 -> 调出
- **业务按钮：**
    - 整单新增调出单：记录新的调出操作。
    - 整单修改调出单：修改现有的调出记录。
    - 整单删除&批量删除：删除不再需要的调出记录。
    - 一键拣货：待拣货的调出单支持拣货，由系统分配库位和批号。
    - 单据打印：打印调出单。
    - 导出&默认方案：将调出记录信息导出为文件，设置或应用调出记录的默认方案。
    - 确认&取消调出：确认物料已经从调出仓库发出，取消已确认的调出操作，恢复库存状态。
    - 审批流及消息提示：提交调出单进行审批，并在审批和操作过程中提供实时消息提示。
    - 关闭&打开单据：关闭当前调出单，禁止进一步操作；重新打开已关闭的调出单，允许编辑。
- 业务数据来源：
    - 从调拨申请中生成，或由仓库管理人员手工录入。
- 业务数据用途：
    - 用于记录物料的实际调出操作。

**【关键数据项】**   字段名称|字段类型|字段长度|是否必填|默认值规则|联动逻辑|调出编码

**【用户界面、交互及输入描述】**

**【处理流程及业务规则、算法描述】**

- 合单调出业务支持
    - 新增调出单：支持选择审批通过，待拣货的调拨申请单。
        - 合单调拨的条件：调出地点一致，则允许合并到一个调出单
            - 调出单行不进行合并
            - 来源字段存到调出单行，多个来源单号拼接存入调入单，并增加筛选条件（不要使用通用来源字段，可新增sourceBillCodes字段存放）

        - 如果选择的调拨申请单已经拣货，则无需再拣货。

### 【处理流程及业务规则、算法描述】

#### 电脑端规则（明盘）

- 整单新增
    - 数据校验规则
        - 存储地点+帐存日期+库位只能同时存在一个进行中的盘点单（库位存在多个或没有，当有交集时则提示xx库位重复，不允许新增盘点单）
        - 按照组织+存储地点+库位+库存分类(取料品档案) 查询库存，并生成【待盘点】明细，需要考虑1w+的数据量的性能问题，如果超过1分钟，则需要考虑异步处理。
            - 系统参数是否使用Erp库存判定
                - 0：使用CJC库存，则查询CJC库存
                - 1：使用ERP库存，则查询ERP库存
                    - 特殊处理1：存储地点的位置属性是自有库存时，不受参数影响（3|4|5）
                    - 特殊处理2：存储地点启用序列号时，也适用自有库存，不受参数影响
    - 联动逻辑：
        - 只能选存储地点下的库位，库位可以多选或者不选
        - 执行人默认当前登录用户对应的人员，支持修改；同时，部门跟着人员联动，反之。
    - 只读逻辑
        - 帐存日期只读
    - 生成【开立】的盘点单
- 整单修改
    - 只读逻辑
        - 存储地点、库位、库存分类（ABC类）、帐存日期只读，其他可改。
- 整单删除&批量删除
    - 【开立】支持删除单据
- 审批流和消息提示
    - 审批通过将单据状态更新为【待盘点】，只有待盘点的支持在手机端盘点，否则提示用户
    - 如果没有启用审批流，则提交即刻审批通过。
- 关闭&打开
    - 除【开立】状态外，均可关闭；记录关闭时间、原因、关闭前的状态，且将所有行关闭。
    - 【关闭】的单据支持打开，重新回到关闭前的单据状态，且将所有行回复。
- 盘点完成
    - 【盘点中】的单据支持手动完成，更新主表和明细行的状态。
    - 记录盘点完成的时间（执行时间)。
- 差异对比
    - 【盘点完成】的单据支持做差异对比，生成盘点差异单，差异单删除时，回复盘点单状态。
- 盘点明细.盘点录入
    - 支持多选料品，录入实盘数量、实盘库位等数据，生成行状态是【待确认】的盘点单明细

单行录入实盘数量、实盘库位等数据。

#### 手机端规则（明盘）

- 盘点单列表
- 列表查询：默认查询【待盘点】【盘点中】的单据，按照盘点时间（计划盘点的时间）倒序。
- 单据扫码：支持扫描盘点单快捷进入明细，扫码默认开启，可在个性化UI中关闭。
- 存储地点或库位扫码：
    - 支持扫描存储地点或库位二维码，依据存储地点或库位查询【待盘点】或【盘点中】的单据，快捷进入物料编辑页面。
    - 启用库位的存储地点扫描，匹配上后快捷进入未盘页面。
- 物料编辑页面
- 默认逻辑：
    - 默认开启物料标签连扫。
    - 料品的不同管理维度设置不同默认值，如实盘数量处理
        - 料品的管理维度为按批次管理或空值，则默认取帐存数量。
        - 料品的管理维度为按数量管理，则默认取标签数量。
- 扫码匹配逻辑：
    - 依据从物料标签中识别的组织+料品+批号+项目号+序列号+任务号+番号+厂牌+库位+存储地点，匹配盘点明细的同一个维度。
        - 没有匹配上，则属于盘盈，帐存数量设置0
        - 匹配上，则录入实际 盘点数量录入，可改
    - 确认按钮
        - 判定盘点单开启复盘，则修改或初始化盘点明细状态【待复盘】
        - 判定盘点单不开启复盘，则修改或初始化盘点明细状态【待确认】
        - 首行盘点，主表记录开始盘点时间
- 已盘页面
    - 盘点完成
        - 同电脑端。

#### 电脑端规则（盲盘）

- 整单新增
    - 新增时不需要拉取库存生成，其他逻辑一致
- 差异对比
    - 【盘点完成】的单据支持做差异对比
        - 查询盘点单的存储地点+库位+库存分类的库存，与实际盘点明细数据对比，匹配组织+存储地点+库位+批号+项目号+序列号+任务号+厂牌维度
            - 有实盘有库存：
                - 实盘 - 库存 < 0，盘亏，记录负数差异数量
                - 实盘 - 库存 > 0，盘盈，记录正数差异数量
            - 没有实盘有库存：
                - 实盘0 - 库存 < 0，盘亏，记录负数差异数量
            - 有实盘没库存：
                - 实盘 - 库存0 > 0，盘盈，记录正数差异数量
        - 生成盘点差异单，差异单删除时，回复盘点单状态。

**手机端规则（盲盘）**

- 默认逻辑：
    - 默认开启物料标签连扫。
        - 料品的不同管理维度设置不同默认值，如实盘数量处理
            - 料品的管理维度为按批次管理或空值，默认 空着 。
            - 料品的管理维度为按数量管理，则默认取标签数量。

## 7、盘点差异

**【功能描述】**   盘点差异用于记录和分析盘点过程中发现的库存差异，以便采取相应的调整措施。

**【功能说明】**

- 业务菜单：仓库管理 -> 盘点管理 -> 盘点差异
- 业务按钮：
    - 整单新增差异单：记录新的盘点差异。
    - 整单修改差异单：修改现有的差异记录。
    - 整单删除&批量删除：删除不再需要的差异记录。
    - 单据打印：打印差异单。
    - 导出：将差异记录信息导出为文件。
    - 默认方案：设置或应用差异记录的默认方案。
    - 审批流及消息提示：提交差异单进行审批，并在审批和操作过程中提供实时消息提示。
    - 关闭&打开单据：关闭当前差异单，禁止进一步操作；重新打开已关闭的差异单，允许编辑。
- 业务数据来源：
    - 从盘点过程中自动生成，或由仓库管理人员手工录入。
- 业务数据用途：
    - 用于分析和处理库存差异。

**【关键数据项】**   字段名称|字段类型|字段长度|是否必填|默认值规则|联动逻辑|差异编码

**【用户界面、交互及输入描述】**

- 以差异记录列表为默认视图，支持根据条件进行查询和筛选。
- 新增或编辑界面中，支持填写差异物料、数量、原因等信息。
- 差异记录查看界面，支持记录的批量操作和单行操作。
- 新增界面设置为两列，包含基本信息和差异详情。

**【处理流程及业务规则、算法描述】**

- 差异编码手动录入或自动生成，编码在系统内唯一。
- 差异记录需经过审核流程。
- 支持按仓库或物料类别进行差异分析。

## 8、形态转换

**【功能描述】**   形态转换用于记录和管理物料在不同形态之间的转换操作，例如从原料到成品的转换。

**【功能说明】**

- 业务菜单：仓库管理 -> 形态管理 -> 形态转换
- 业务按钮：
    - 整单新增转换单：记录新的形态转换操作。
    - 整单修改转换单：修改现有的转换记录。
    - 整单删除&批量删除：删除不再需要的转换记录。
    - 单据打印：打印转换单。
    - 导出：将转换记录信息导出为文件。
    - 默认方案：设置或应用转换记录的默认方案。
    - 审批流及消息提示：提交转换单进行审批，并在审批和操作过程中提供实时消息提示。
    - 关闭&打开单据：关闭当前转换单，禁止进一步操作；重新打开已关闭的转换单，允许编辑。
- 业务数据来源：
    - 由生产或仓库管理人员根据实际需求手工录入。
- 业务数据用途：
    - 用于记录物料的形态转换操作。

**【关键数据项】**   字段名称|字段类型|字段长度|是否必填|默认值规则|联动逻辑|转换编码

**【用户界面、交互及输入描述】**

- 以转换记录列表为默认视图，支持根据条件进行查询和筛选。
- 新增或编辑界面中，支持填写转换物料、数量、源形态、目标形态等信息。
- 转换记录查看界面，支持记录的批量操作和单行操作。
- 新增界面设置为两列，包含基本信息和转换详情。

**【处理流程及业务规则、算法描述】**

- 转换编码手动录入或自动生成，编码在系统内唯一。
- 转换完成后，需更新库存记录。
- 支持按物料类别或转换类型进行形态转换操作。
