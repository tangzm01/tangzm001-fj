## 2\. 功能概述

### 2.1 业务背景

销售业务在出库环节会涉及两类源单据：

- **销售订单发货单**：按销售订单/出货计划发货产生的正式出库依据，常见于内贸、整批交付；
- **其他出库单**：非订单驱动的杂项出库，包括样品、赠品、调拨、维修件、客诉补发、补件等。

两类源单据在仓库实操中都需要进一步**装箱**才能交付或发运。当前 cjcloud 销售装箱单主要由电脑端维护，但现场作业（尤其是异形件、小批量、SKU 较多的场景）需要仓管员/搬运工拿着移动设备就近扫码装箱，减少来回往返电脑端。

**装备行业特殊场景（磨粉机）**：磨粉机作为大型整机设备，业务上按整机签单与结算，物流上必须按组件拆分装箱发货。即：

- 销售订单的"产品"是"磨粉机（整机）"；
- 销售订单发货单（或出货计划展开后的发货单）上的物料可能是整机或关键部件；
- 同一项目可能既有销售订单发货单，又有其他出库单（如补件、附件、随机工具、随机备件、安装件等），需要在一次装箱作业中**合并扫码**生成一张装箱单；
- BOM 中标记"装箱拆卸"的物料在出库时需要单独打**拆卸物料标签**，便于拆包后追溯；
- 物料档案标记"安装件"的物料需要打**安装件物料标签**，便于现场装配识别；
- 装箱清单（含箱号/物料/数量/重量体积）必须 PC 端打印，作为出库随货凭证。

### 2.2 功能目标

1.  在 PC 端完善销售装箱单的查询、新增、编辑、审核、打印、附件上传、绑定发运单能力；
2.  在手机端提供扫码入口，支持扫**销售订单发货单**或**其他出库单**条码生成装箱单；
3.  **支持 1 张销售订单发货单 + N 张其他出库单**（同项目）合并扫码生成一张装箱单；
4.  扫物料时**默认数量 = 该物料在该源单据中的剩余可装箱数量**，支持手动调整；
5.  支持**安装件 / 拆卸件**两类标识联动：物料档案"安装件"标识 + BOM"装箱拆卸"标识共同决定装箱时是否拆开、是否打印对应标签；
6.  PC 端完成**装箱清单打印**与**安装件 / 拆卸件标签打印**；
7.  PC 端支持上传**装箱照片**作为装箱单附件；
8.  装箱数据自动回写至源单据（销售订单发货单、其他出库单），并在销售订单追溯页可被查看；
9.  PC 与手机端共用同一套状态机、数量口径、数据权限，确保一致性。

### 2.4 功能范围

#### 本期范围

- 销售装箱单 PC 端全生命周期管理（查询、新增、编辑、审核、弃审、关闭、删除、打印、附件、绑发运）；
- 销售装箱单 PC 端明细行与箱号管理（含安装件、拆卸件标识）；
- 销售装箱单 手机端 扫码入口，支持扫**销售订单发货单**或**其他出库单**条码；
- 手机端**多源单据合并扫码**（1 张销售订单发货单 + N 张其他出库单，同项目）；
- 扫物料时默认按单据数量装箱，可手动调整；
- 安装件与拆卸件标签 PC 端打印；
- 装箱清单 PC 端打印；
- 装箱照片附件上传（PC）；
- 装箱单与销售订单发货单 / 其他出库单的回写；
- 装箱单与发运单的关联（一键生成 / 绑定）；
- PC 与手机端状态机、数量口径、数据权限统一。

#### 本期非目标

- 手机端不实现完整的设计与打印模板编辑；
- 手机端不开放物料、客户、仓库等主数据维护；
- 手机端**不支持离线作业**（必须有网络），所有扫码与提交实时同步；
- 不实现自动化立体库 / AGV 联动、机器视觉自动量方、自动称重；
- 不改变现有源单据（销售订单发货单、其他出库单）的业务流程；
- 不实现客户外部签收小程序；
- 不在本期做财务结算或开票集成；
- 整机销售订单与销售订单发货单之间的拆分规则不在本期重新定义，按现有"销售订单 → 出货计划 → 销售订单发货单"链路执行。

### 2.5 核心业务规则

| 规则项 | 规则内容 |
| --- | --- |
| 单据归属 | 销售装箱单隶属于"销售管理 / 履约执行"，与销售订单、出货计划、销售订单发货单、其他出库单、发运单同一业务链路。 |
| 来源单据 | 销售装箱单必须关联至少一个来源单据：**销售订单发货单**或**其他出库单**；**支持 1 张销售订单发货单 + N 张其他出库单合并**生成一张装箱单，多源单据必须归属同一项目（销售订单）。 |
| 一对多 | 一个源单据可对应多张装箱单；一张装箱单可包含多张源单据（同项目）；多源合并时数量分别扣减各自源单据的剩余可装箱数量。 |
| 单据状态机 | 统一状态：`草稿 → 待审核 → 已审核 → 装箱中 → 已完成 → 已关闭`，并支持 `已删除` 旁支。手机端提交后进入 `待审核` 或 `装箱中`，依业务规则而定。 |
| 箱号  | 箱号在同一装箱单内必须唯一；可由系统按规则自动生成（如 PKG-001 起始），支持手动调整；箱号变更需保留历史。 |
| SN 与批次 | 当源单据物料启用 SN 或批次管理时，装箱明细必须填写 SN 或批次号，否则不可提交。 |
| 数量校验 | 装箱数量不得超过源单据剩余可装箱数量；超量提示并阻止保存；负数（退箱）需业务确认。 |
| 默认装箱数量 | 手机端扫物料时，**默认数量 = 该物料在该源单据中的剩余可装箱数量**（多源合并时分别按各自源单据计算），可手动调整。 |
| 主辅单位 | 物料启用主辅单位时，必须分单位展示和合计，不得跨单位直接相加。 |
| 包装信息 | 毛重、净重、体积、件数按箱汇总，并自动汇总到装箱单抬头。 |
| 安装件 | 物料档案标记"安装件"=是 的物料，在销售订单发货单上识别为安装件；可在销售订单发货单上打印**安装件物料标签**；手机端扫该物料时显示"安装件"标识。 |
| 拆卸件 | BOM 子项标记"装箱拆卸"=是 的物料，在拆分发货时需要单独拆开装箱；在装箱单上识别为拆卸件；可在装箱单上打印**拆卸物料标签**。 |
| 整机拆分 | 磨粉机等大型整机产品：销售订单/生产订单上的产品为整机；销售订单发货单上的物料可能为整机或拆分后的部件；按 BOM 与装箱拆卸标识决定是否拆分装箱。 |
| 状态回写 | 装箱单审核/完成后，将已装箱数量、箱数回写到源单据；源单据已装箱数达到出库数量时，源单据进入"已装箱"状态。 |
| 下游联动 | 已完成装箱单可一键生成发运单或将多张装箱单绑定到同一张发运单。 |
| 权限  | 按组织、仓库、销售员、客户等数据权限过滤；手机端扫码仅在授权仓库范围内生效。 |
| 网络  | 手机端**不支持离线**；扫码、提交、查询均需联网；网络异常时直接阻断操作并提示，不缓存本地数据。 |
| 打印  | 装箱清单、安装件物料标签、拆卸物料标签均**在 PC 端打印**；手机端不开放打印功能（可查看但不能调起打印机）。 |

## 3\. 用户使用流程

### 3.1 PC 端主流程

| 步骤  | 用户操作 | 系统处理 | 结果  |
| --- | --- | --- | --- |
| 1   | 进入"销售装箱单"菜单 | 加载查询条件和默认数据范围 | 展示装箱单列表 |
| 2   | 输入编码、客户、日期、状态、来源单据类型并查询 | 按数据权限查询 | 展示符合条件的装箱单 |
| 3   | 点击"新增" | 弹出新建对话框 | 进入新建页 |
| 4   | 选择来源单据类型（销售订单发货单 / 其他出库单） | 弹出对应参照 | 选择具体源单据 |
| 5   | 支持继续追加"其他出库单"（多张） | 校验同项目、同客户、同仓库 | 多源合并带入 |
| 6   | 系统带入所有源单据抬头与明细 | 校验源单据状态、剩余可装箱数量 | 展示可装箱明细 |
| 7   | 编辑箱号、SN、批次、毛/净重、体积、件数 | 实时校验数量、SN 唯一、批次存在性 | 明细行即时校验 |
| 8   | 系统自动识别安装件 / 拆卸件并打标 | 根据物料档案与 BOM 标识自动识别 | 明细行展示标识 |
| 9   | 保存草稿 / 提交审核 | 校验必填项与权限 | 草稿或待审核 |
| 10  | 审核  | 校验关联源单据状态、权限 | 已审核 / 退回 |
| 11  | 装箱中维护（按需） | 允许手机端回填、调整明细 | 装箱中 |
| 12  | 完成装箱 | 校验所有明细已装箱、汇总数量 | 已完成 |
| 13  | 打印装箱清单 | PC 端生成套打模板 | 装箱清单 PDF/纸质 |
| 14  | 打印安装件 / 拆卸件标签（按需） | 按标识筛选物料标签 | 安装件 / 拆卸件标签 |
| 15  | 上传装箱照片附件 | PC 端上传到装箱单附件库 | 附件留痕 |
| 16  | 绑发运单 | 一键生成或绑定发运单 | 装箱 → 发运衔接 |

### 3.2 手机端主流程（扫码生成销售装箱单）

| 步骤  | 用户操作 | 系统处理 | 结果  |
| --- | --- | --- | --- |
| 1   | 进入手机端"装箱作业"入口 | 校验手机端权限与仓库范围、网络状态 | 展示扫码页 |
| 2   | 选择扫码模式：销售订单发货单 / 其他出库单 | 切换扫描模式 | 唤起扫码 |
| 3   | 扫描第一张源单据条码 | 调用条码识别 → 调用源单据接口 | 展示源单据抬头与可装箱明细 |
| 4   | 如需追加"其他出库单"，切换为其他出库单模式继续扫码 | 校验同项目、同客户、同仓库 | 多源合并带入 |
| 5   | 系统按箱规则预生成箱号，提示"是否开始装箱" | 校验剩余可装箱数量 | 进入装箱页 |
| 6   | 逐件扫描物料 SN / 批次 | 实时校验：SN 唯一、批次存在、数量未超；**默认数量 = 该物料在源单据中的剩余可装箱数量**，可调整 | 累计已装、剩余 |
| 7   | 识别安装件 / 拆卸件并提示 | 根据物料档案与 BOM 标识实时打标 | 标识展示 |
| 8   | 录入箱号、包装、净/毛重、体积、件数 | 自动汇总当前箱 | 当前箱数据完整 |
| 9   | 一键"换箱"或"多件一箱" | 切换/合并箱号 | 多个箱号并存 |
| 10  | 装箱完成 → 提交 | 校验全部装箱完成、超量、漏装、错装 | 装箱单进入待审核/装箱中 |
| 11  | 网络异常 | 直接阻断操作并提示，不缓存 | 等待网络恢复 |

### 3.3 装箱 → 发运衔接流程

```text
销售订单（磨粉机整机）
  └─ 出货计划
       └─ 销售订单发货单 ─┐
                          ├─ 销售装箱单 ── 发运单 ── 签收
其他出库单（补件、附件、随机工具）┘
```

- **方式 A**：装箱完成后，由 PC 端"一键生成发运单"，系统带入箱数、总毛重/净重/体积、收货信息；
- **方式 B**：在发运单页面"多选装箱单"绑定到同一张发运单，适合一车多货；
- **方式 C**：手机端装箱完成后不直接生成发运单，由 PC 端触发。

### 3.4 异常分支

- **源单据未审核或已关闭**：禁止生成装箱单，提示"请先审核销售订单发货单/其他出库单"；
- **源单据已被完全装箱**：禁止重复装箱，提示"该单据已装箱完成，请查看历史装箱单"；
- **多源合并不同项目**：禁止合并，提示"销售订单发货单与其他出库单必须归属同一项目（销售订单）"；
- **多源合并不同客户或不同仓库**：禁止合并，提示"客户或仓库不一致"；
- **源单据存在退货或红冲**：提示是否计入剩余可装箱数量（默认不计，由实施确认）；
- **扫码识别失败**：支持手工输入条码，并提示校验失败原因；
- **SN 重复扫描**：实时提示"该 SN 已被当前箱或其他箱装箱"，需确认是否补扫或退箱；
- **超量装箱**：实时提示"已超过源单据剩余可装箱数量 X"，阻止提交；
- **漏装**：装箱完成时若仍有剩余未装箱物料，提示"还有 X 件未装箱"，允许强制提交或补装；
- **错装（物料不对应）**：扫码物料与当前箱预期物料不一致时，强提示并阻止；
- **手机端网络异常**：直接阻断操作，提示"网络异常，请检查网络后重试"，**不缓存本地数据**；
- **PC 与手机端同时编辑同一装箱单**：进入互锁模式，后进入者提示"该单据正在被 XXXX 编辑，是否只读查看"；
- **打印模板缺失**：提供默认模板或提示"未配置模板，请联系管理员"；
- **发运单已生成但装箱单被删除**：发运单提示"关联装箱单已删除"，需物流人员确认后再发运；
- **安装件物料已全部装完**：提示"该安装件已全部装箱，无需再拆"；
- **拆卸件未单独打标签**：提交时提示"存在 N 个拆卸件未打标签，请 PC 端打印标签后装箱"。

| 状态  | 含义  | 允许操作 | 触发条件 |

| 标识  | 数据来源 | 业务含义 |

| 拆卸件 | BOM 子项"装箱拆卸"=是 | 该物料为整机拆分出的部件，需单独装箱；需打拆卸物料标签 |
| 整机  | 销售订单"产品"层级，整机产品（如磨粉机） | 业务上按整机签单，物流上按组件拆分装箱 |

#### 4.12.1 整机拆分场景示例（磨粉机）

```text
销售订单（销售订单号 SO20260729001）
  └─ 产品：磨粉机 MP-100（整机）
       └─ 销售订单发货单 DEL20260729001
            ├─ 物料：磨粉机主机 MP-100-M  （非安装件、非拆卸件，整机发货）
            ├─ 物料：控制柜 MP-100-C     （非安装件、拆卸件 = 是）
            ├─ 物料：电机组件 MP-100-E   （非安装件、拆卸件 = 是）
            ├─ 物料：随机工具 MP-100-T   （非安装件、拆卸件 = 是）
            └─ 物料：安装件 A1           （安装件 = 是、拆卸件 = 是）
       └─ 其他出库单 OUT20260729001（同项目）
            ├─ 物料：备件 B1            （非安装件、非拆卸件）
            └─ 物料：附件 C1            （非安装件、非拆卸件）

销售装箱单 PKG20260729001（合并 DEL + OUT）
  ├─ 箱 PKG-001：磨粉机主机
  ├─ 箱 PKG-002：控制柜 + 电机组件 + 随机工具（拆卸件，需打拆卸物料标签）
```

#### 4.12.2 手机端扫码时的提示规则

- 扫到**安装件**时：顶部提示"该物料为安装件，是否装箱？"；
- 扫到**拆卸件**时：顶部提示"该物料为拆卸件，需单独打标签"；
- 扫到**整机物料**时：顶部提示"该物料为整机主体"；
- 扫到**不属于当前源单据的物料**时：提示"物料与源单据不一致"，阻止。

### 4.13 手机端：装箱确认提交

| 步骤  | 操作  | 说明  |
| --- | --- | --- |
| 1   | 检查所有源单据的装箱进度 | 全部装完则可提交 |
| 2   | 若仍有未装物料 | 提示"还有 X 件未装箱"，允许强制提交或补装 |
| 3   | 网络异常 | 阻断并提示"网络异常，请检查网络后重试"（不缓存） |
| 4   | 提交成功 | 装箱单进入"待审核"或"装箱中"，源单据已装箱数量回写 |
| 5   | 通知 PC 端 | 实时刷新装箱单状态 |

### 4.14 公共：状态、权限、数量口径

- **状态机**：PC 与手机端共用同一状态机，手机端不开放"弃审、删除、打印"操作；
- **数量口径**：
    - 主辅单位分单位展示；
    - 多源合并时按源单据分别扣减剩余可装箱数量；
    - 同一物料在同一装箱单内的总数量不得超过源单据剩余可装箱数量；
    - 已删除装箱单不计入已装箱数量但保留追溯；
    - 红冲 / 退货源单据是否计入剩余可装箱数量由实施确认，默认不计；
- **数据权限**：按组织、仓库、销售员、客户授权；手机端只展示当前用户仓库范围的源单据；
- **功能权限**：按角色控制新建、编辑、审核、弃审、删除、绑发运、生成发运、模板配置、上传附件等。

### 4.15 公共：与追溯页集成

- 销售订单追溯页（已存在）中增加"装箱单"分区，展示装箱单编码、来源单据类型、箱数、件数、毛重/体积、安装件 / 拆卸件数量、状态；
- 装箱单编码支持新页签打开；
- 追溯页"已装箱数量"字段按本 PRD 数量口径汇总。

## 7\. 原始需求描述

### 7.1 用户原始需求（V1.0 → V2.0 更新）

> 分析当前开发环境，销售装箱单功能，反向推出 PRD。有电脑端和手机端，手机端支持扫描销售发货单或者杂发单据生成销售装箱单。
> 
> **V2.0 更新**：
> 
> - 手机端（非 H5），不支持离线；
> - 功能：扫销售订单发货单和其他出库单（其他出库单可多扫，同项目）生成装箱单；
> - 扫物料默认数量是单据数量进行装箱，可打装箱清单，上传照片；
> - 需要拆开装箱的产品，物料档案标记安装件，BOM 中拆卸物料标记装箱拆卸标识；
> - 销售订单--出货计划--销售发货按产成品操作，销售订单发货单上有安装件时，可打印安装件物料标签；
> - 操作：扫销售订单发货单和其他出库单，打印拆卸物料，扫物料，装箱确认，打印清单，上传附件照片附件；
> - 装箱单打印需要在 PC 端完成；
> - 场景是磨粉机的发货（业务上整机、物流上组件）。

### 7.2 需求结构化整理

1.  销售装箱单存在电脑端，需要梳理现有功能并形成 PRD；
2.  增加手机端扫码能力（**非 H5、不支持离线**）；
3.  手机端支持扫描**销售订单发货单**生成装箱单；
4.  手机端支持扫描**其他出库单**生成装箱单；
5.  **支持 1 张销售订单发货单 + N 张其他出库单（同项目）合并扫码**生成一张装箱单；
6.  扫物料默认数量 = 源单据剩余可装箱数量；
7.  **安装件**物料档案标识，**拆卸件**BOM 标识联动识别；
8.  装箱清单、安装件 / 拆卸件标签均 PC 端打印；
9.  PC 端上传装箱照片附件；
10. 装箱数据回写源单据并可被销售订单追溯页查看；
11. 装箱单与发运单联动；
12. 装备行业（磨粉机）整机拆分场景支持。

### 7.3 本 PRD 补充内容

- PC 端查询、新增、编辑、审核、打印、附件、绑发运全生命周期；
- 手机端多源合并扫码、默认数量规则、安装件/拆卸件识别；
- PC 与手机端状态机与数量口径统一、互锁；
- 追溯页集成与已装箱数量回写；
- 测试用例、实施确认清单、风险与交付确认。

## 8\. 开发规范

### 8.1 数据与状态规范

- 装箱单编码由系统统一生成；前缀 PKG，按日期或流水递增；
- 主数据使用内部主键关联源单据、销售订单、客户、仓库、项目；
- 多源合并时必须建立"装箱单 → 多源单据"的关联表，记录每张源单据的已扣减数量；
- 状态机在 PC 与手机端共用同一套配置；
- 删除、关闭、红冲、退货等单据的统计口径必须统一；
- 主辅单位分别存储和展示；
- **安装件**物料档案字段、`装箱拆卸` BOM 子项字段需在主数据模块维护。

### 8.2 接口与性能规范

- 源单据接口、装箱单接口、手机端扫码接口均使用统一的鉴权与幂等机制；
- 手机端**实时联网**，所有扫码与提交均调用服务端接口；
- 装箱明细分页拉取，避免一次返回大量明细；
- 打印使用异步任务；
- 多源合并接口需返回各源单据的剩余可装箱数量，默认数量计算在服务端完成。

### 8.3 权限与审计规范

- PC 与手机端共用数据权限；
- 敏感字段（金额、收货人电话、地址）按角色脱敏；
- 记录创建、扫码、提交、审核、弃审、删除、生成发运单、上传附件日志；
- 多源合并需记录每次合并的源单据与数量扣减明细。

### 8.4 手机端开发规范

- 手机端适配主流机型与系统浏览器；
- 扫码组件封装统一接口，支持手动输入；
- **必须联网**，断网直接阻断并提示，不缓存本地数据；
- 不开放打印功能；
- 网络异常、断线超时统一由拦截器处理。

### 8.5 打印与标签规范

- 装箱清单、安装件标签、拆卸件标签均按客户/仓库/项目/物料维度配置模板；
- 标签条码内容至少包含：物料编码、装箱单编码、箱号、客户；
- 支持连续纸、激光、针式打印机；
- 缺失模板时使用默认模板或提示联系管理员。

### 8.6 整机拆分规范（磨粉机类）

- 销售订单 / 生产订单上的产品为整机；
- 销售订单发货单上的物料按 BOM 展开，可能含整机与组件；
- BOM 子项维护"装箱拆卸"标识，用于决定是否单独装箱与打标签；
- 整机物料不强制拆分，按业务需要执行；
- 组件按"拆卸件"标识单独装箱并打拆卸物料标签；
- 安装件按物料档案"安装件"标识打安装件标签。

### 8.7 明确不开发内容

本期不开发：

- 自动化立体库、AGV、机器视觉量方；
- 客户外部签收小程序；
- 财务结算与开票集成；
- 在装箱单页面修改销售订单或销售订单发货单的核心业务字段；
- 跨订单经营分析与 BI 报表；
- 手机端离线缓存与断网提交；
- 手机端打印功能（仅 PC 端打印）。

### B. 风险与应对

| 风险  | 影响  | 建议措施 |
| --- | --- | --- |
| 源单据未带稳定来源关系 | 装箱单关联错误或断裂 | 使用内部主键和来源关系表，必要时补建关联 |
| 手机端断网但仍需作业 | 业务中断 | 明确告知"手机端不支持离线"；安排网络保障（仓库 Wi-Fi/4G） |
| 多源合并时数量跨源挪用 | 汇总数量失真 | 强制按源单据独立扣减，禁止跨源挪用 |
| 安装件 / 拆卸件标识缺失 | 整机拆分场景无法识别 | 上线前盘点 BOM 与物料档案，补齐标识 |
| 现有源单据流程变更 | 装箱流程不匹配 | 评审确认源单据状态机，建立同步通知 |
| 打印模板缺失 | 现场无法贴标 | 提供默认模板，允许管理员在线配置 |
| 手机端权限过大 | 越权装箱 | 按仓库/角色严格控制，并审计扫码日志 |
| 发运单已签收但装箱单被删除 | 物流对账异常 | 删除前强制校验下游状态，提示并保留追溯 |
| 扫描 SN 漏扫或错扫 | 漏装错装 | 启用 SN/批次校验、自动换箱与强提示 |
| 附件照片存储容量 | 附件过多占用存储 | 限制单文件大小与装箱单总附件大小，定期归档 |
| 整机拆分边界不清 | 误拆或漏拆 | 由业务提供整机清单与组件清单，实施顾问维护 BOM |

- 数据权限矩阵；
- 敏感字段脱敏方案；

- 上线范围、验收标准和上线计划。
