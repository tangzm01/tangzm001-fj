# 🔮 概述

## 1、 用户故事

作为仓储管理员，小李希望通过智能仓储系统自动处理销售订单，以便在订单生成后，系统能够自动识别库存位置，并生成相应的拣货单和发货计划。这样，他可以快速处理出库流程，确保准确无误的发货，提高客户满意度，并减少人为错误，从而提升整体运营效率。通过系统的实时更新，小李还能随时追踪订单状态，优化仓储管理。

用户反馈

- 系统对接不畅：销售模块与其他系统（如ERP、CRM）的接口不顺畅，导致数据无法实时更新和同步。
- 库存实时性问题：库存信息更新不及时，导致销售人员无法准确了解库存情况，影响订单处理。
- 拣货效率低：拣货路径规划不合理，导致拣货效率低下，影响发货速度。
- 订单处理延迟：订单从生成到发货的过程存在延迟，影响客户交货时间和满意度。
- 发货错误率高：发货过程中频繁出现错误，如发错商品或数量不对，影响客户体验。

# 📙 单据

## 1、销售订单

**【功能描述**】

管理客户订单的接收和处理过程，确保订单的准确性与及时性。该模块支持快速创建和审核订单，自动计算总金额，并实时跟踪订单状态。通过集成的流程，企业能够提高销售效率，优化库存管理，提升客户服务响应速度。

**【功能说明】**

- **业务菜单**：销售管理 -> 订单管理 -> 销售订单
- **业务按钮**：
    - 新增订单：直接创建销售订单，输入客户信息和产品详细信息。
    - 依库存制单：依据库存创建销售订单
    - 修改&批量修改订单：对已开立的订单进行修改。
    - 删除&批量删除订单：删除不再需要的订单记录。
    - 查询订单：根据条件查询历史订单。
    - 审批流和消息提示：消息默认通知到消息中心。
    - 关闭&打开：订单关闭后不允许做后续业务。
    - 单据打印：批量打印订单单据。
    - 导入：设置导入模板，导入EXCEL数据。
    - 导出&默认方案：导出订单信息并保存默认导出方案。

**【处理流程及业务规则】**

- 单据号自动生成，默认编码规则设置为单据简写-组织编码-YYMMDD-4位流水，SO-101-250120-0001
- 整单新增&保存并提交
    - 支持选择料品档案新增
        - 规则1：支持选择多个料品，录入本次销售数量或者件数
            - 料品单位设置固定转换率时，根据转换率自动计算
            - 料品单位设置无换算时，件数等于销售数量，不可编辑
            - 料品单位设置浮动换算时，销售数量和件数允许编辑，不联动
    - （5.7.0）支持依据库存新增
        - 规则1：料号、品名、规格型号均支持打开选择料品参照
        - 规则2：依据库存新增时，弹出{库存参照页面}
        - 规则3：库存查询
            - 默认排序规则：库存批次正序、托盘号正序、存储地点、库位、料品
            - 默认条件规则：客户编码、存储地点编码
        - 规则4：选择托盘，自动带出托盘下的物料，支持移除
        - 规则5：可以选择同一个客户或者不带客户的库存，不可选择多个客户的库存
        - 规则6：根据库存配料完成后，按料品汇总订货数量，支持在订单行查看配货明细，重新点击可修改配货结果，修改后将订货数量、件数、总长度等信息回写到明细。
        - 规则7：行编辑时，按库存新增的行，复制时提示不允许操作，可选择库存追加
    - 单据保存规则
        - 相同料品，相同交期合并到销售订单明细，选择的配货信息单独存入配货明细，并回写已配货数量
        - 保存时，支持修改销售数量，≥配货数量。
- 删除&批量删除限制逻辑
    - 有后续单据不允许删除
    - 审批通过不允许删除
- 修改限制逻辑
    - 审批通过不允许修改
- 关闭&打开：
    - 规则1：累计出货数量大于等于销售订单数量，则系统自动关闭
    - 规则2：手动关闭时，记录关闭状态，支持打开回到关闭前的状态
    - 规则3：关闭后，不允许做后续业务；如果存在已经生成的单据，业务还未完成，例如：已生成出货计划或者销售发货单，在回写销售订单累计数量时，提示订单已经关闭，不支持做相关业务。
- 导入
    - 支持批量导入多个订单，最少需要支持20单，每单20行
- 审批流&消息提醒
    - 配置单节点审批流，即提交即审核
        - 规则1：【开立】状态下支持提交审核
        - 规则2：审批通过后
            - 数据下推
                - 全部按库存配货，则保存并自动提交出货计划，生成【待发货】的出货计划。
                - 部分按库存配货，部分转生产，则将已配货部分保存为草稿，生成【开立】的出货计划。
                - 未配货部分：可手动转【开立】的生产订单，待生产完成，成品入库后，继续配货。
            - 销售订单明细数据变化，增加已配货数量
                - 已配货数量≥销售数量；单据状态变更为【待发货】
                - 已配货数量＞0，已配货数量＜销售数量；单据状态变更为【部分配货】
                - 已配货数量=0；单据状态变更为【待配货】
        - （5.7.0）调用NCC销售订单创建并审核接口（前提：接口配置中，开启与NCC系统对接）
        - （5.7.0）回写逻辑：NCC单号与行号
    - 弃审
        - 规则：有后续单据不允许弃审
        - （5.7.0）调用NCC销售订单弃审并删除接口（前提：接口配置中，开启与NCC系统对接）
        - （5.7.0）回写逻辑：清空NCC单号与行号
- （5.7.0）手动配货
    - 规则1：操作剩余需要配货的订单明细，选择新生产的成品库存进行配货
        - 数量允许比订货数量小，支持部分配货
    - 规则2：配货后占用库存，不允许其他人使用
    - 规则3：支持清空配货结果，重新配货（出货计划未审核前，可在清空配货结果时自动删除出货计划数据）
    - 规则4：支持同一个客户的多个订单一起配货
    - 规则5：支持同一个订单多次配货
    - 规则6：确认配货即刻生成【开立】的出货计划，回写订单明细的累计出货计划数量（已配货数量）。
        - 当存在相同客户和销售部门，且出货计划单据状态是【开立】的单据，则提示用户是否追加
        - 当存在多张【开立】的单据，则显示出货计划（单号、销售部门、创建人、创建时间）供销售人员选择
- （5.7.0）销售订单明细功能（开立状态才能生效，非开立状态不允许操作）
    - 批量新增：
        - 追加销售订单明细，物料支持多选，自动添加多行后手动配料。
    - 批量修改：支持修改单价、金额、交期和未配货的订货数量、申请生产数量，如果已配货，则到手动配货，重新选择清空配货结果后再修改或删除
    - 批量删除：没有后续单据，支持删除行
    - 申请生产：明细上，未配料的订货数量，支持发起生产，按明细上的申请生产数量转【开立】的生产订单。

## 2、出货计划

**【功能描述】**

优化发货安排，确保按时交付产品。此模块帮助企业制定和调整出货计划，匹配库存与订单需求，合理分配物流资源。通过实时状态更新和执行监控，企业可以提高物流效率，减少发货延迟，提高客户满意度。

**【功能说明】**

- **业务菜单**：销售管理 -> 出货管理 -> 出货计划
- **业务按钮**：
    - 依销售订单新增：依据销售订单创建出货计划。
    - 修改&批量修改计划：调整出货计划的详细信息。
    - 删除&批量删除计划：删除不再需要的出货计划记录。
    - 查询计划：根据条件查找历史出货计划。
    - 一键拣货：选择多个出货计划拣货，成功后生成销售发货单。
    - 取消拣货：选择’已拣货‘的单据取消，同步删除销售发货单。
    - 确认出货：未出货的行支持生成出货单。
    - 审批流&消息提示
    - 数据同步：同步ERP出货计划。
    - 单据打印：批量打印出货计划单据。
    - 导出&默认方案：导出计划信息并保存默认导出方案。

**【处理流程及业务规则】**

- 依销售订单新增
    - 选择可出货计划量 > 0的销售订单计划行，创建出货计划，创建后回写可出货计划量
    - 允许同一个客户合并出货计划

- 修改&批量修改计划：
    - 保存状态的单据，新增的字段皆可修改。（注意数量的回写）
    - 审批通过后，只允许修改联系人、备注等文本字段。
- 删除&批量删除计划：删除不再需要的出货计划记录，回写销售订单数据。
- 查询计划：
    - 根据条件查找历史出货计划。
    - 跨组织出货业务支持，创建组织和发货组织均可见。
- 审批流&消息提示
    - 提交
    - 审批通过
        - 规则1：单据状态变更为【待发货】
        - 规则2：保存并提交销售发货单（若发货单没有设置审批流，则直接审批通过，使用PDA扫码出库）
        - 规则3：一张销售订单可以多次做出货计划，出货计划和NCC发货单一一对应。
        - （5.7.0）调用NCC发货单创建并审核接口（前提：接口配置中，开启与NCC系统对接）
        - （5.7.0）回写逻辑：NCC单号与行号
    - 弃审
        - 规则：有后续单据不允许弃审（系统自动生成的，且没有被操作，则可直接回退）
        - （5.7.0）调用NCC发货单弃审并删除接口（前提：接口配置中，开启与NCC系统对接）
        - （5.7.0）回写逻辑：清空NCC单号与行号

    - 选择多个出货计划拣货，根据存储地点+项目号拣货，项目号匹配库存规则：有-有，有-空，空-空。

    - 增加系统参数模板，控制是否允许部分拣货
    - 出货计划数量和拣货数量不同，需回写销售订单。
- 取消拣货：

    - 销售发货单后续动作还未开始。
    - 数量回复

## 3、销售发货单

**【功能描述**】

记录订单的出库和发货详情，确保物流准确性。该模块支持批量生成和管理发货单，自动同步库存数据，并提供快速查询和打印功能。通过简化的发货流程，企业可以降低出错率，提升客户体验。

**【功能说明】**

- **业务菜单**：销售管理 -> 发货管理 -> 销售发货单
- **业务按钮**：
    - 删除&批量删除发货单：删除不再需要的发货单记录。
    - 查询发货单：根据条件查找历史发货记录。
    - 审批流和消息提示：消息默认通知到消息中心。
    - 一键拣货：根据需要发货的明细拣货，按拣货规则匹配批号、库位等。
    - 销售调拨：对配置了待发货仓储的明细，支持提前将物料调拨到发货仓。
    - 确认发货&取消发货：确认并记录实际发货信息。
    - 单据打印：批量打印发货单据。
    - 导出&默认方案：导出发货单信息并保存默认导出方案。
- **发货明细业务按钮：**
    - 理货：支持手动选择出货的批号、库位。
    - 打印标签：支持选择发货明细打印唛头。
    - 批量取消下架：手机端扫码下架，未发货确认前，支持取消下架，重新扫码。
    - 查看发货库位明细：同一批物料，支持从多个库位发货
    - 删除发货明细：保存状态下，支持删除发货明细，回写销售订单或发货计划累计发货数量。

**【处理流程及业务规则】**

- 新增发货单限制条件：
    - 先选择客户，联动销售订单或出货计划选择；如果先选订单或出货计划，则自动带出客户。
    - 如选择了待发货仓库，则拣货完成后，可触发调拨业务，并控制先调拨后发货。
- 修改发货单：
    - 审批通过后不允许修改
- 删除&批量删除
    - 审批通过后不允许删除
- 调拨限制
    - 拣货完毕，且维护了待发货仓支持调拨
    - 发货完成后不允许再操作
- 扫码发货
    - 料品未启用序列号，扫描物料标签发货
    - 料品启用序列号，扫描序列号标签发货
    - （5.7.0）扫描托盘标签发货
        - 支持扫描托盘标签，托盘标签中可以获取到料品、库存批次、序列号信息，并且可得知托盘上的货物件数，料品和件数相同则允许匹配出库
    - （5.7.0）序列号出库
        - 支持扫描托盘标签和序列号标签出库
        - 在发货明细界面，扫描库位标签后，扫描物料标签，判定出库料品是否启用序列号，启用则跳转到序列号出库界面
        - 当扫描托盘码时，如果料品+批号+出库件数相同，则允许出库
    - 增加组织级系统参数，是否严格按系统拣货结果出库
        - 是：扫描出货数据条件必须与出货行的存储地点+库位+料品+批号+项目号+番号+序列号维度相同，允许出库。
        - 否：扫描出货数据条件与出货行的存储地点+库位+料品维度相同，批号、项目号、番号或序列号不相同也允许出库
            - 项目号不同，不能出其他项目号，但支持出空项目号
            - 批号不同，按实物批号修改出货信息，并出货
            - 番号不同，按实物番号修改出货信息，并出货
            - 序列号不同，按实物序列号修改出货信息，并出货
- 确认发货：
    - 规则1：验证发货信息后，更新状态为“发货完成”。
    - 规则2：扣减占用的库存
    - 规则3：启用序列号料品，处理外部接口逻辑和库存更新逻辑，与仓储管理的处理方式保持一致
        - 在CJC启用序列号库存，外部系统启用批号库存，出库量将按批号汇总后调用
        - 在CJC启用序列号库存，外部系统也启用序列号，则直接对接即可
        - 在CJC启用序列号库存，外部系统不启用库存，则无需对接
- 取消确认
- （5.7.0）增加NCC系统对接
    - 确认发货：
        - 规则1：销售发货单与NCC出库单一一对应。
        - （5.7.0）调用NCC发货单创建并审核接口（前提：接口配置中，开启与NCC系统对接）
        - （5.7.0）回写逻辑：NCC单号与行号
    - 取消发货
        - 规则：有后续单据不允许弃审（系统自动生成的，且没有被操作，则可直接回退）
        - （5.7.0）调用NCC发货单弃审并删除接口（前提：接口配置中，开启与NCC系统对接）
        - （5.7.0）回写逻辑：清空NCC单号与行号
