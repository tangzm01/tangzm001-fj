# 📙 基础数据

## 产能维护（ok）

**【功能描述】**

产能维护功能主要用于对计划排产中的基础数据进行管理，具体是对工作中心的产能相关信息进行新增、编辑、批量操作以及生效和失效控制等。通过该功能，用户可以准确设置工作中心、产线、设备等相关产能参数，如小时产能、每日运行时长等，为后续的计划排产提供准确可靠的基础数据支撑，以确保生产计划的合理性和可行性。

**【功能说明】**

- **业务菜单**：计划排产 -> 基础数据 -> 产能维护
- **业务按钮**：
    - 左树：工作中心
    - 新增：点击后可进入新增产能信息的页面，用于添加单个产能相关记录。
    - 批量新增：可选择工作中心、设备、料号，批量新增
    - 编辑：点击后可对选中的单条产能记录进行编辑操作。
    - 批量编辑：可对选中的多条产能记录进行批量编辑。
    - 生效/失效：用于控制产能记录的生效或失效状态，并记录相应的时间。
- **单据来源**：--
- **单据去向**：--

**【处理流程及业务规则、算法描述】**

- **新增**
    - 校验同一生效、失效范围内，工作中心、产线、设备组、设备、班组、料号，只能有一条
    - 可以不选择设备或班组，代表该规则对所有设备组、班组都适用
- **批量新增**
    - 校验规则同新增功能
    - 可多选设备、料品，取选择结果的笛卡尔积，如设备2个，料品3个，最终结果为6行
- **编辑/批量编辑**
    - 校验规则同新增功能
    - 若小时产能或每日运行时长发生变化，系统应自动重新计算日产能。
- **生效/失效**
    - 检查生效是否影响唯一性校验
    - 如果校验通过，系统将该规则的状态标记为 生效/失效，并记录生效失效时间
    - 控制生效/失效按钮显隐

## 排产策略（ok）

**【功能描述】**

排产参数模块用于管理排产规则，支持对排产方案进行增删改查操作，为计划排产提供基础设置。在进行生产订单排产时，需先选择合适的排产规则，从而实现对生产订单的合理安排。

**【功能说明】**

- **业务菜单**：计划排产 -> 基础数据 -> 排产策略
- **业务按钮**：
    - 左树：工作中心
    - 新增：创建新的排产方案。
    - 编辑：修改选中排产方案的相关信息。
    - 删除：删除选中的排产方案。
    - 生效/失效：对选中的排产方案进行生效或失效操作
- **单据来源**：--
- **单据去向**：--

## 齐套方案（缺少加项减项）

**【功能描述】**

齐套分析方案用于构建一套对库存及相关参数进行分析的体系，通过主子表结构，记录方案基本信息、可用量参数以及存储地点参数，以实现对库存可用量及不同存储地点参与运算情况的综合分析，为业务决策提供数据依据。

**【功能说明】**

- **业务菜单**：计划排产 -> 齐套分析 -> 齐套方案
- **业务按钮**：
    - 新增：创建新的齐套分析方案
    - 可用量参数页签：可勾选哪些单据的数量参与计算库存可用量，如现存量、产成品待入量、委外待入量、调拨待发量等
    - 存储地点页签：可勾选哪些存储地点的库存数量参与计算库存可用量
    - 编辑：可编辑主子表的参数设置
    - 删除：删除整个齐套分析方案
    - 生失效：针对主表的是否生效字段进行操作，控制方案是否可用于实际分析
- **单据来源**：用户手动创建
- **单据去向**：--

**【处理流程及业务规则、算法描述】**

- **新增**
    - 保存时校验可用量参数、存储地点至少各勾选一个
    - 新增完成后，系统自动生成方案编号
    - 分析策略
        - 按生产数量分析：按生产订单-剩余开工数量进行分析备料齐套情况。
            - 如果选择按生产数量分析，则齐套分析时录入的分析数量无效
        - 按指定套数分析：用户可以自己指定分析数量，填入“分析数量”字段中，但指定的套数不可以超过剩余开工数量。
    - 订单优先级策略
        - 预设优先级：对于每张订单，用户都可以自由定义排程时的优先级，优先级取值从0~99
            - 如果选择按预设优先级进行分析，则录入优先级的订单按优先级排序，没有录入优先级的订单按选择顺序排序，且有优先级>无优先级
            - 如果不是按预设优先级进行分析，则录入的优先级不进行排序
        - 生产周期：为该生产订单，在不考虑资源的能力占用情况下，静态的总生产提前期。
            - 工艺路线增加 加工工时倍数增加 字段，默认否，订单确认、派工时带到生产订单、派工单
            - 若为是，则生产周期= Σ（各工序加工工时 × 订单数量） + Σ 各工序准备工时
            - 若为否，则生产周期= Σ 各工序加工工时  + Σ 各工序准备工时
        - 交货期：该生产订单的计划完工时间
        - 紧迫系数：为该订单生产周期与可用工作时间（计划完工日期-当前时间-工作日历节假日）的比值，该值有效反映了订单的生产紧迫程度。
            - 紧迫系数=生产周期/计划完工日期-当前时间-工作日历节假日
        - 瓶颈资源利用率：识别企业生产过程中的瓶颈资源（如关键设备、关键技术人员等），优先安排能够使瓶颈资源利用率最大化的订单进行生产。通过优化瓶颈资源的使用，可以提高整个生产系统的产出效率。（先不做）
    - BOM 分析方式
        - 逐阶考虑库存：BOM 有多层时，每一层的成品、半成品均考虑库存；
        - 只考虑末级库存：分析时，只考虑最末级材料的库存，产品本身及中间半成品均不考虑库存。
- **可用量页签**
    - 默认全选
    - 获取可用数据时，只考虑单据状态是审批通过的单据，保存、审批中的不考虑
    - 加项
        - 现存量：ERP实时库存的主数量之和，不区分批号
        - 请购量：请购单状态为XX的数量
        - 采购送货预约在途量：已送货预约
        - 采购送货申请在途量：数量
        - 采购待收货数量：采购收货单中
        - 采购待入库数量：
        - 现存量：来源于 ERP 系统中实时库存的主数量之和，在统计时不区分批号。
        - 请购量：数据来源于请购单，具体是请购单状态为特定状态（需明确 XX 具体状态，如 “已审核未执行” 等）的数量。请购单是企业内部各部门向采购部门提出采购需求的单据，符合特定状态的请购量可以反映出未来可能补充到库存中的物料数量，从而影响齐套分析中的可用量计算。
        - 采购订单在途量：数据取自采购订单模块，指已下达采购订单但尚未入库的物料数量，包含未审核状态的采购订单数量（“含未审”）。采购订单在途量体现了企业已经确定采购但还未实际收到的物料情况，对于评估未来库存的补充有重要参考价值。
        - 进货待入量：一般来源于企业的进货业务流程中，已确认采购但尚未完成入库操作的物料数量。它反映了即将进入库存的物料情况，是可用量计算中的一个积极因素。
        - 采购入库待入量：通常与采购订单的后续执行情况相关，是指已经完成采购流程但还未完成最终入库确认的物料数量。这部分数量在入库后将增加库存现存量，影响齐套分析结果。
        - 调拨在途量：数据来源于企业内部不同仓库或存储地点之间的物料调拨业务。当发生物料调拨时，处于运输途中的物料数量即为调拨在途量，它反映了企业内部库存的动态变化情况，在计算库存可用量时需要考虑这部分数量。
        - 其他在途量：涵盖了除上述明确列举之外的，处于运输或流转过程中、未来会增加库存的物料数量。例如企业可能存在一些特殊的采购渠道或物流方式导致的在途物料，这部分数量也会对库存可用量产生影响。
        - 生产待产量：取自生产模块，指已有生产订单但未开工的物料数量。
        - 生产在产量：取自生产模块，指正在生产线上加工制造的产品或半成品对应的物料数量。
        - 生产待入量：通常是指生产部门已经完工但还未进入成品仓库的产成品数量。完工申报中
        - 委外待入量：指委托外部加工单位进行加工生产，目前已完成加工但尚未返回企业入库的物料数量，“含未审” 即包含未审核的委外待入库单据。委外待入量在入库后会增加企业库存，对库存可用量产生影响。
        - 委外入库待入量：是委外加工业务中，已经确定要入库但还未完成实际入库操作的物料数量。这部分数量在入库后会增加库存，是库存可用量的一个重要组成部分。
    - 减项
        - 安全库存：料品档案中维护的安全库存数量。
        - 最低库存：料品档案中维护的最低库存数量。
        - 销售订单占用量：来源于销售订单模块，指已经接到客户订单但尚未发货的产品或物料数量。
        - 销货待出量：指已经确认销售但尚未实际发货的产品或物料数量。它与销售订单占用量有一定关联，但更侧重于实际销售流程中处于待发货状态的物料数量，在计算库存可用量时需要从现存量中扣除这部分数量。
        - 销售出库待出量：是指在销售出库流程中，已经完成出库准备但尚未实际发出的产品或物料数量。这部分数量在实际发货后将减少库存，是库存可用量的一个减项因素。
        - 调拨待发量：来源于企业内部的物料调拨业务，指已经安排从当前仓库或存储地点调拨出去，但尚未实际发出的物料数量。调拨待发量会减少当前仓库的库存可用量。
        - 要货待发量：通常是指企业内部不同部门或分支机构之间的要货请求中，已经确认但尚未发货的物料数量。这部分数量在发货后会减少库存，是库存可用量的减项之一。
        - 其他待发量：涵盖了除上述明确列举之外的，已经确定要从库存中发出但尚未实际发货的物料数量。例如企业可能存在一些特殊的业务需求导致的待发货情况，这部分数量也会对库存可用量产生影响。
        - 生产占用量：取自生产模块，指正在生产过程中被占用的物料数量，包括正在加工、装配等环节使用的物料。生产占用量在生产完成前会一直占用库存，是库存可用量的减少因素。
        - 生产待发量：通常是指生产部门已经计划领用但尚未实际从仓库领取的物料数量，“含未审” 表示包含未审核的生产待领料记录。这部分数量在实际领料后会减少库存，是库存可用量的减项之一。
        - 材料待发量：指生产部门为了满足生产需求，已经申请但尚未实际领取的原材料数量。材料待发量在实际领用后会减少库存，影响库存可用量的计算。
        - 委外待发量：指委托外部加工单位进行加工生产时，已经确定要发给委外加工单位但尚未实际发出的物料数量。委外待发量在发货后会减少企业库存，是库存可用量的减项因素。
        - 委外发料待发量：是委外加工业务中，已经计划发给委外加工单位但尚未实际发出的原材料数量。这部分数量在实际发料后会减少库存，对库存可用量的计算产生影响。
- **存储地点页签**
    - 默认展示全部存储地点
    - 可新增、删除
- **编辑**
    - 编辑主表信息时，可重新选择分析策略、订单优先级策略、BOM 分析方式等，修改后下次分析时生效。
    - 编辑可用量参数子表时，可重新勾选或取消勾选需要考虑的单据数量，修改后下次分析时生效。
    - 编辑存储地点参数子表时，可新增或删除存储地点是否参与运算，修改后下次分析时生效。
- **删除**
    - 删除时需提示用户确认删除操作，删除后相关数据无法恢复。
- **生/失效**
    - 检查生效是否影响唯一性校验
    - 如果校验通过，系统将该规则的状态标记为 生效/失效，并记录生效失效时间
    - 控制生效/失效按钮显隐

## 齐套分析（缺少缺料明细部分）

**【功能描述】**

齐套分析模块主要用于对生产订单及生产备料的相关数据进行分析，以判断物料是否齐全配套，保障生产的顺利进行。通过该模块，用户可以创建、查看齐套分析，根据不同的分析类型（按生产订单、按生产备料）进行相应操作， 并对相关数据进行编辑、保存等处理。

**【功能说明】**

    - 删除：删除齐套分析记录

    - 生产备料页签：查看选择的生产订单中，根据料品汇总的备料明细
- **单据来源**：用户手动创建
- **单据去向**：--

**【处理流程及业务规则、算法描述】**

- **新增**
    - 选择齐套方案：从有效方案中选择
    - 选择模拟日期：默认当前日期，只可选择当前或未来日期，用于模拟分析场景
    - 选择生产订单
        - 系统校验订单状态，只能选择有剩余开工数量的订单
        - 选择后在下方表格显示选择的生产订单，多次选择的为追加显示
        - 选择生产订单，在备料页签中增加显示该生产订单的备料信息，默认只查询需要齐套分析的内容（需要在物料清单中增加字段“是否齐套分析”）
        - 备料页签料品排序时先按料品排序，再按订单优先级排序
    - ~~选择分析类型：选择备料或预订单等细分类型。~~
    - ~~系统参数配置：判断是否考虑过期情况（如有相关系统参数配置）。~~
    - 数据录入与编辑：用户可编辑分析数量、手动优先级等字段。系统根据录入或编辑的数据进行初步校验（如数据格式、取值范围等）
    - 点击保存按钮，系统将录入或编辑的数据保存到数据库，生成齐套分析单据记录和编号
    - 点击保存并分析按钮，系统先保存数据，然后执行齐套分析功能
- **齐套分析**
    - 根据选择的模拟日期、齐套方案、生产订单及录入的数据进行齐套分析算法计算
        - 按照齐套方案选择的优先级规则对生产订单进行排序
        - 按照模拟日期：查询库存预测报表中，对应备料的当日的库存量查询
        - 按照齐套方案选择的可用量参数、存储地点参数进行计算库存
        - 更新相关字段值，如生产订单页签：是否齐套、齐套数量、未齐套数量等，生产备料页签：可领数量、差异数量。
        - 分析结果包含孙表，可查看每个订单对应的备料占用的库存，以及对应料品的库位、批量等。
- **生成缺料信息**
- **编辑**
    - 没有进行齐套分析的单据可以编辑
- **删除**
    - 删除时需提示用户确认删除操作，删除后相关数据无法恢复
