# 🔐 排产约束

1.  **资源约束（设备/人员/场地）**
    1.  **资源可用性限制​**
        1.  设备需排除保养/维修时段（通过EAM接口获取）
        2.  人员可用性取决于排班计划（班组→班次→排班表）
        3.  场地可用性基于部门关联的工作日历
    2.  **资源产能上限**​
        1.  最大产能限制：资源当日需求时长 ≤ 24小时
        2.  单资源单工序：∑(单日所有工序需求时长) ≤ 资源最大产能
        3.  修改限制：批量修改产能时不超过资源档案维护的最大产能
    3.  **资源匹配规则**​
        1.  并行占用：时长不变（如场地）
        2.  并行加工：时长=原时长/资源数（如设备）
2.  **时间约束**
    1.  **工序时间计算**
        1.  前后工序
        2.  资源需求时长
    2.  **特殊时间规则**​
        1.  工作日历影响：场地/设备按部门日历，人员按班次
        2.  )00非工作时间排除：节假日自动跳过
        3.  锁定保护：锁定工序时间不会被自动计算覆盖

# 💻 操作流程

1.  进入页面、选择订单、排序优先级
2.  调整资源（系统计算产能）、调整关键工序计划开完工时间、锁定关键工序
3.  计划预排（系统计算开工完工时间）、手动调整
4.  查看负荷

## 产能维护

**【功能描述】**

产能维护模块用于统一管理产品（料品）生产过程中的资源需求配置、产能基准数据及换线策略，通过建立料品-工序-资源的多级关联关系，为精准排产提供核心数据支撑。系统支持基于资源类型（设备/场地/人员）的弹性产能配置，实现生产能力的动态平衡与优化。

**【功能说明】**

    - 编辑：修改主表和子表信息
    - 删除：删除产能维护记录
- **单据来源**：手动创建，料品档案、工艺路线、资源档案
- **单据去向**：生产调度、产能计算

## 齐套方案V1.0

**【功能描述】**

齐套分析方案用于构建一套对库存及相关参数进行分析的体系，通过主子表结构，记录方案基本信息、可用量参数以及存储地点参数，以实现对库存可用量及不同存储地点参与运算情况的综合分析，为业务决策提供数据依据。

**【功能说明】**

- **业务菜单**：计划排产 -> 基础数据 -> 齐套方案
- **业务按钮**：
    - 新增：创建新的齐套分析方案
    - 可用量参数页签：可勾选哪些单据的数量参与计算库存可用量，如现存量、产成品待入量、委外待入量、调拨待发量等
    - 存储地点页签：可勾选哪些存储地点的库存数量参与计算库存可用量
    - 编辑：可编辑主子表的参数设置
    - 删除：删除整个齐套分析方案
    - 生失效：针对主表的是否生效字段进行操作，控制方案是否可用于实际分析
- **单据来源**：手动创建
- **单据去向**：生产调度、产能计算

**【处理流程及业务规则、算法描述】**

- **新增**
    - 保存时校验可用量参数、存储地点至少各勾选一个
    - 新增完成后，系统自动生成方案编号
    - 分析策略
        - 按生产数量分析：按生产订单-剩余开工数量进行分析备料齐套情况。
            - 如果选择按生产数量分析，则齐套分析时录入的分析数量无效
        - 按指定套数分析：用户可以自己指定分析数量，填入“分析数量”字段中，但指定的套数不可以超过剩余开工数量。
    - 订单优先级策略
        - 预设优先级：对于每张订单，用户都可以自由定义排程时的优先级，优先级取值从0~99
            - 如果选择按预设优先级进行分析，则录入优先级的订单按优先级排序，没有录入优先级的订单按选择顺序排序，且有优先级>无优先级
            - 如果不是按预设优先级进行分析，则录入的优先级不进行排序
        - 交货期：该生产订单的计划完工时间
        - 紧迫系数：为该订单生产周期与可用工作时间（计划完工日期-当前时间-工作日历节假日）的比值，该值有效反映了订单的生产紧迫程度。
            - 紧迫系数=生产周期/计划完工日期-当前时间-工作日历节假日
    - BOM 分析方式
        - 逐阶考虑库存：BOM 有多层时，每一层的成品、半成品均考虑库存；
        - 只考虑末级库存：分析时，只考虑最末级材料的库存，产品本身及中间半成品均不考虑库存。
- **可用量页签**
    - 默认全选
    - 获取可用数据时，只考虑单据状态是审批通过的单据，保存、审批中的不考虑
    - 加项
        - 现存量：ERP实时库存的主数量之和，不区分批号
        - 请购量：请购单状态为XX的数量
        - 采购送货预约在途量：已送货预约
        - 采购送货申请在途量：数量
        - 采购待收货数量：采购收货单中
        - 采购待入库数量：
        - 现存量：来源于 ERP 系统中实时库存的主数量之和，在统计时不区分批号。
        - 请购量：数据来源于请购单，具体是请购单状态为特定状态（需明确 XX 具体状态，如 “已审核未执行” 等）的数量。请购单是企业内部各部门向采购部门提出采购需求的单据，符合特定状态的请购量可以反映出未来可能补充到库存中的物料数量，从而影响齐套分析中的可用量计算。
        - 采购订单在途量：数据取自采购订单模块，指已下达采购订单但尚未入库的物料数量，包含未审核状态的采购订单数量（“含未审”）。采购订单在途量体现了企业已经确定采购但还未实际收到的物料情况，对于评估未来库存的补充有重要参考价值。
        - 进货待入量：一般来源于企业的进货业务流程中，已确认采购但尚未完成入库操作的物料数量。它反映了即将进入库存的物料情况，是可用量计算中的一个积极因素。
        - 采购入库待入量：通常与采购订单的后续执行情况相关，是指已经完成采购流程但还未完成最终入库确认的物料数量。这部分数量在入库后将增加库存现存量，影响齐套分析结果。
        - 调拨在途量：数据来源于企业内部不同仓库或存储地点之间的物料调拨业务。当发生物料调拨时，处于运输途中的物料数量即为调拨在途量，它反映了企业内部库存的动态变化情况，在计算库存可用量时需要考虑这部分数量。
        - 其他在途量：涵盖了除上述明确列举之外的，处于运输或流转过程中、未来会增加库存的物料数量。例如企业可能存在一些特殊的采购渠道或物流方式导致的在途物料，这部分数量也会对库存可用量产生影响。
        - 生产待产量：取自生产模块，指已有生产订单但未开工的物料数量。
        - 生产在产量：取自生产模块，指正在生产线上加工制造的产品或半成品对应的物料数量。
        - 生产待入量：通常是指生产部门已经完工但还未进入成品仓库的产成品数量。完工申报中
        - 委外待入量：指委托外部加工单位进行加工生产，目前已完成加工但尚未返回企业入库的物料数量，“含未审” 即包含未审核的委外待入库单据。委外待入量在入库后会增加企业库存，对库存可用量产生影响。
        - 委外入库待入量：是委外加工业务中，已经确定要入库但还未完成实际入库操作的物料数量。这部分数量在入库后会增加库存，是库存可用量的一个重要组成部分。
    - 减项
        - 安全库存：料品档案中维护的安全库存数量。
        - 最低库存：料品档案中维护的最低库存数量。
        - 销售订单占用量：来源于销售订单模块，指已经接到客户订单但尚未发货的产品或物料数量。
        - 销货待出量：指已经确认销售但尚未实际发货的产品或物料数量。它与销售订单占用量有一定关联，但更侧重于实际销售流程中处于待发货状态的物料数量，在计算库存可用量时需要从现存量中扣除这部分数量。
        - 销售出库待出量：是指在销售出库流程中，已经完成出库准备但尚未实际发出的产品或物料数量。这部分数量在实际发货后将减少库存，是库存可用量的一个减项因素。
        - 调拨待发量：来源于企业内部的物料调拨业务，指已经安排从当前仓库或存储地点调拨出去，但尚未实际发出的物料数量。调拨待发量会减少当前仓库的库存可用量。
        - 要货待发量：通常是指企业内部不同部门或分支机构之间的要货请求中，已经确认但尚未发货的物料数量。这部分数量在发货后会减少库存，是库存可用量的减项之一。
        - 其他待发量：涵盖了除上述明确列举之外的，已经确定要从库存中发出但尚未实际发货的物料数量。例如企业可能存在一些特殊的业务需求导致的待发货情况，这部分数量也会对库存可用量产生影响。
        - 生产占用量：取自生产模块，指正在生产过程中被占用的物料数量，包括正在加工、装配等环节使用的物料。生产占用量在生产完成前会一直占用库存，是库存可用量的减少因素。
        - 生产待发量：通常是指生产部门已经计划领用但尚未实际从仓库领取的物料数量，“含未审” 表示包含未审核的生产待领料记录。这部分数量在实际领料后会减少库存，是库存可用量的减项之一。
        - 材料待发量：指生产部门为了满足生产需求，已经申请但尚未实际领取的原材料数量。材料待发量在实际领用后会减少库存，影响库存可用量的计算。
        - 委外待发量：指委托外部加工单位进行加工生产时，已经确定要发给委外加工单位但尚未实际发出的物料数量。委外待发量在发货后会减少企业库存，是库存可用量的减项因素。
        - 委外发料待发量：是委外加工业务中，已经计划发给委外加工单位但尚未实际发出的原材料数量。这部分数量在实际发料后会减少库存，对库存可用量的计算产生影响。
- **存储地点页签**
    - 默认展示全部存储地点
    - 可新增、删除

        - 默认全部历史生产订单：订单状态为“订单确认”“派工中”“已派工”（不考虑暂停的生产订单）的生产订单，查询订单开工日期小于分析的生产订单号的计划开工日期了
        - 默认所有生产订单：订单状态为“订单确认”“派工中”“已派工”的生产订单，查询所有生产订单，包含未来的生产订单但优先级高于当前订单，影响排序规则
        - 默认特定条件历史生产订单：爱发科特定逻辑，待提供
        - （新增）不考虑任何订单：没有订单占用的情况
        - （新增）手动选择订单：仅分析手动选择的订单占用情况
    - 是否考虑完工领料（优先级低）
        - 特殊场景：完工后仍需再领料
        - 不考虑完工领料：分析占用订单中，不含“完工中”“完工”“自动关闭”“手动关闭”的生产订单，此类订单认为已完成，不再领料
        - 考虑完工领料：分析占用订单中，增加“完工中”“完工”“自动关闭”“手动关闭”的生产订单，逐一计算备料是否有剩余领料数量
    - 是否专料可用通用料（非专料专用）
        - 是：备料所需的库存中有通用料，此生产订单可以用通用料
        - 否：备料所需的库存中有通用料，但不能用必须要项目号匹配才能使用
    - 是否考虑过期供应
        - 特殊场景：依据开工时间计算时当天缺料，但延期几天（过期供应天数）后就不缺料
        - 不考虑：分析缺料情况时，如果分析订单的计划开工时间内物料未齐套，则标记缺料
        - 考虑：分析缺料情况时，如果分析订单的计划开工时间内物料未齐套，但计划开工日期+过期供应天数后可以齐套，则标记过期齐套
        - 维护为是时，过期供应天数必填，否则禁填

# 📙 计划排产

## 齐套分析（待定）

**【功能描述】**

齐套分析模块主要用于对生产订单及生产备料的相关数据进行分析，以判断物料是否齐全配套，保障生产的顺利进行。通过该模块，用户可以创建、查看齐套分析，根据不同的分析类型（按生产订单、按生产备料）进行相应操作， 并对相关数据进行编辑、保存等处理。

**【功能说明】**

- **业务菜单**：计划排产 -> 齐套分析 -> 齐套分析
- **业务按钮**：
    - 新增：创建新的齐套分析记录
    - 删除：删除齐套分析记录
    - 生失效：针对主表的“是否生效”字段进行操作，控制方案是否可用于实际分析
    - 可用量参数页签：可勾选哪些单据的数量参与计算库存可用量（加项与减项）
    - 存储地点页签：可勾选哪些存储地点的库存数量参与计算库存可用量
- **单据来源**：用户手动创建
- **单据去向**：--

**【处理流程及业务规则、算法描述】**

- **新增**
    - 选择齐套方案：从有效方案中选择
    - 选择模拟日期：默认当前日期，只可选择当前或未来日期，用于模拟分析场景
    - 选择生产订单
        - 系统校验订单状态，只能选择有剩余开工数量的订单
        - 选择后在下方表格显示选择的生产订单，多次选择的为追加显示
        - 选择生产订单，在备料页签中增加显示该生产订单的备料信息，默认只查询需要齐套分析的内容（物料清单字段whole_set_flag）
        - 备料页签料品排序时先按料品排序，再按订单优先级排序
    - ~~选择分析类型：选择备料或预订单等细分类型。~~
    - ~~系统参数配置：判断是否考虑过期情况（如有相关系统参数配置）。~~
    - 数据录入与编辑：用户可编辑分析数量、手动优先级等字段。系统根据录入或编辑的数据进行初步校验（如数据格式、取值范围等）
    - 点击保存按钮，系统将录入或编辑的数据保存到数据库，生成齐套分析单据记录和编号
    - 点击保存并分析按钮，系统先保存数据，然后执行齐套分析功能
- **齐套分析**
    - 根据选择的模拟日期、齐套方案、生产订单及录入的数据进行齐套分析算法计算
        - 按照齐套方案选择的优先级规则对生产订单进行排序
        - 按照模拟日期：查询库存预测报表中，对应备料的当日的库存量查询
        - 按照齐套方案选择的可用量参数、存储地点参数进行计算库存
        - 更新相关字段值，如生产订单页签：是否齐套、齐套数量、未齐套数量等，生产备料页签：可领数量、差异数量。
        - 分析结果包含孙表，可查看每个订单对应的备料占用的库存，以及对应料品的库位、批量等。
- **生成缺料信息**
- **编辑**
    - 没有进行齐套分析的单据可以编辑
- **删除**
    - 删除时需提示用户确认删除操作，删除后相关数据无法恢复

    - ~~选择分析类型：选择备料或预订单等细分类型。~~

    - 点击保存并分析按钮，系统先保存数据，然后执行齐套分析功能
- **齐套分析**
    - 根据选择的模拟日期、齐套方案、生产订单及录入的数据进行齐套分析算法计算（简易）
        - 生产订单优先级-按开工日期升序排序，不做占用逻辑
        - 配置项：“是否专料专用”，爱发科默认为是
            - 是：如果生产订单主表有项目号，则查询条件为：料品+项目号，如果没有项目号，则查询条件为料品+空项目号
            - 否：如果生产订单主表有项目号，则优先使用带项目号的料品，如果没有项目号，则都可用
        - 在库可用量=SUM(ERP实时库存/CJC库存  WHERE 料品=当前料号 AND (项目号=生产订单项目号 OR 项目号 IS NULL) AND 库存状态=可用)
        - 在制可用量＝SUM(派工单生产数量-派工单完工数量  WHERE 料品=当前料号 ~~AND 计划完工日期>=模拟日期~~ AND (项目号=生产订单项目号 OR 项目号 IS NULL) AND 单据状态=开工)
        - 在制齐套日=MAX（对应派工单计划完工日期）
        - 在途可用量＝SUM(采购订单计划行剩余可送货数量 WHERE 料品=当前料号 ~~AND 预计到货日期>=模拟日期~~ AND (项目号=生产订单项目号 OR 项目号 IS NULL) )
        - 在途齐套日=MAX（对应采购订单交期）
    - 计算齐套率、是否齐套、齐套日
        - 生产备料
            - 料品齐套计算数量-在库-在制-在途>=0，则计算齐套率=（在库+在制+在途）/料品齐套计算数量，齐套日=MAX（在途齐套日，在制齐套日），标记是否齐套为否
            - 料品齐套计算数量-在库-在制-在途<0，则齐套率=100%，齐套日显示为空，标记是否齐套为是
        - 生产订单
            - 如果生产订单下的备料全部齐套，则标记是否齐套为是，否则为 否
            - 不齐套时，齐套日期显示为 max(备料齐套日期)
    - 计算缺料
        - 缺料量=MAX(0, 料品齐套计算数量 - 可用总量)，防止计算出负数
    - 生成缺料信息
        - 按照料品汇总缺料量
- **编辑**
    - 没有进行齐套分析【状态未待分析】的单据可以编辑  OK
- **删除**
    - 删除时需提示用户确认删除操作，删除后相关数据无法恢复

                - 选择料品后，查询该料品有无 主BOM数据，如果有，则自动变更为否
                - 保存、版本变更、共用料、保存并升版时，校验同一料品只能有一个主BOM，否则提示“同一料品只能有一个主BOM”
            - 料品档案
                - 增加料品形态属性：制造件、采购件、外购件
                - 增加提前期：制造提前期、采购提前期等字段，并增加同步U9
        - 备料获取，根据生产订单主表的bom_id，获取物料清单的生产目的、版本、用途、项目号、客户、产地，查询子表的+生效+审批通过，如果没有，则取料品+主BOM的物料清单和子表，如果还没有，就不继续展开了
        - 如果料品的形态属性为采购件、外购件的，则不展开BOM
        - 齐套分析的数量为剩余领料数量，展开BOM后计算也使用剩余领料数量\*bom子表的基本用量/子表的母件底数，计算结果根据单位精度取整或保留小数位数
        - 物料范围
            - 如果为齐套标识，则查询备料时只查询齐套标识（物料清单whole_set_flag）的备料
            - 如果为全部，则查询全部备料
            - 如果为非倒冲物料，则查询物料清单中发料方式不为完工倒冲的
            - 如果上层BOM不在范围内，则不继续展开
        - BOM 分析方式（暂时没用上）
            - 逐阶考虑库存：BOM 有多层时，每一层的成品、半成品均考虑库存；
            - 只考虑末级库存：分析时，只考虑最末级材料的库存，产品本身及中间半成品均不考虑库存。
        - BOM展开后需要标记阶码
        - BOM展开后标记路径长度
    - 点击保存按钮，系统将录入或编辑的数据保存到数据库，生成齐套分析单据记录和编号
    - 点击保存并分析按钮，系统先保存数据，然后执行齐套分析功能
- **齐套分析**
    - 展开BOM生成计划订单
        - 生成计划订单，计划订单号是生产订单号+BOM+BOM阶码拼接，生产订单不生成计划订单
        - 根据前面选择的所有分析订单+所有生产订单（去重），逐一做BOM展开，展开方式同上
        - 展开的BOM数量计算方式同上
        - 展开后，根据料品的提前期，计算计划开始日期
            - 搜索料品档案的提前期，如果是制造件，查询制造提前期，采购件查询采购提前期，委外件查询委外提前期
            - 变动提前期：如果为变动提前期，则根据分析数量/批量\*提前期
            - 如果没维护，则为0
            - 结束日期=上阶BOM的计划订单的计划交期
            - 开始日期=此计划订单计划交期-提前期
            - 示例数据
            - ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1wvqreb1PeYG2nak/img/4e1dc59e-076a-4945-902a-e0bf9801ec28.png)
    - 计算需求
        - 根据计划订单、生产订单（分析订单+生产订单）所有计划交期，计算每日需求数量
        - 按照日期+料品汇总计算，前端展示每日需求数量表格
        - 示例数据
        - ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1wvqreb1PeYG2nak/img/5420b06c-d637-4897-a335-766dd4ada530.png)
    - 计算供应
        - 根据齐套方案的维护的供应范围计算数据
        - 存储地点：只查询固定存储地点的库存信息
        - 可用量
            - 库存数量=库存可用量+待检在库量，供应日期为当前日期
            - 采购在途数量=采购待收数量和+采购已收待入数量，供应日期为采购订单的交期（deliveryDay）
            - 委外在途数量=委外待收数量+委外已收待入数量，供应日期为委外订单的交期deliveryDay
            - 计划在制数量=第一步根据bom展开的计划订单的，料品为自制件的计划生产数量，供应日期为计划订单的结束日期
            - 生产在制数量=生产订单可生产数量，供应日期为生产订单计划完工日期
            - 可靠在制数量=生产在产量+生产待入量+对计划在制和生产在制分析后的可靠数量，供应日期为派工单计划完工日期
                - 系统参数：在制订单是否默认交期可靠性，如果是，则此处的可靠在制=生产在产量+生产待入量+计划在制数量+生产在制数量数量，默认为是
        - 根据以上可用量的所有计划结束时间，计算每日供应数量
        - 按照日期+料品汇总计算，前端展示每日需求供应表格
        - 示例数据
        - ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1wvqreb1PeYG2nak/img/426bd5cb-a23f-42a4-8594-d25b474d665e.png)
    - 供需匹配
        - 需要计算当日累计非在制供应=前一日剩余+当日库存+当日采购+当日委外
        - 当日剩余=当日累计非在制+当日可靠在制-当日需求
        - 示例数据
        - ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1wvqreb1PeYG2nak/img/ae74991b-9f06-474a-bfbf-674bc55f5386.png)
    - 计算分析对象是否齐套
        - 根据分析对象的BOM，开始找到最长的bom路径，从阶码最小的料品的计划订单开始分析供需匹配，查看交期当日供应-需求是否满足
        - 如果自制件
            - 前提！先查看当日累计非在制供应+可靠需求数量-需求是否满足，
                - 如果满足，需要标记供应占用，此物料的是否齐套为“齐套”
            - 如果没有齐套，则查看此自制品有无 计划完工日期在分析计划订单的计划开始日期 当日或++之前++的 生产订单和计划订单
                - 如果有，则分析在制订单的交期可靠性，顺序为计划开始时间从小到大
                - 如果没有齐套，则查看此自制品有无 计划完工日期在分析计划订单的计划开始日期 ++之后++的 生产订单和计划订单，顺序为计划开始时间从小到大
                    - 如果有，则分析在制订单的交期可靠性
                - 如果还没有齐套，则创建一个新的计划订单，开始日期为今天，完工日期为今天+提前期（同样考虑变动/固定提前期），并展开需求，更新需求表，并分析此订单的交期可靠性
                - 系统参数：在制订单是否默认交期可靠性，如果是，则此处不继续分析在制订单交期可靠性，默认可靠，爱发科为是
            - 在制订单交期可靠性
                - 分析在制订单是否齐套
                - 展开BOM-找到最长的bom路径-供需匹配，和齐套分析一致
                - 最早齐套日期=MAX（分析对象订单下的备料最早齐套日期）
                - 最早交期=最早齐套日期+提前期
        - 如果外购件/采购件
            - 查看当日累计非在制供应-需求是否满足，如果满足，需要标记占用，且此物料的是否齐套为“齐套”
            - 如果不满足，记录满足的数量，并查看有无未来日期的此料品的采购订单，累计数量满足分析的生产订单数量时，获取最晚采购订单交期作为此料品的最早齐套日期，且此物料的是否齐套为“部分齐套”
            - 如果没有单据，则创建一个新的计划订单，数量为缺少的料品数量，开始日期为今天，交期日期为今天+提前期日期，作为最早齐套日期，并更新供应表，且此物料的是否齐套为“短缺”
            - 如果单据数量累计不足，则创建一个新的计划订单，数量为缺少的料品数量，开始日期为今天，交期日期为今天+提前期日期，作为最早齐套日期，交期日期为MAX（今天+提前期日期，原有单据的最晚交期），并更新供应表，且此物料的是否齐套为“短缺”
        - 回写分析对象结果
            - 如果分析对象订单下的所有备料都齐套，则是否齐套为“齐套”
            - 如果分析对象订单下的备料有 部分齐套，则是否齐套为“部分齐套”
            - 如果分析对象订单下的备料有短缺，则是否齐套为“短缺”
            - 齐套日期=MAX(分析对象订单下的备料最早计划完工日期)

## 细能力计划（有限产能排产）

**【功能描述】**

细能力平衡模拟模块支持在资源约束条件下进行设备级排产，通过动态计算设备负载与工序时长相匹配关系，优化生产订单执行顺序。系统将采用左右分栏结构直观展示订单工序信息与设备占用甘特图。

**【功能说明】**

- **业务菜单**：计划排产 -> 基础数据 -> 细能力计划
- **业务按钮**：
- \*\*左树：\*\*工作中心、料品排产分类
- **左区功能​**
    - 生产订单列表
    - 优先规则切换：`预设优先级`/`交货期`/`紧迫系数`
    - 优先级排序：按照排序规则，对生产订单进行排序
    - 修改：可编辑优先级排序
- **右区功能**​
    - 批量锁定/单行锁定​：锁定所有工序的计划时间
    - 批量解锁/单行解锁​：锁定所有工序的计划时间
    - 计划预排：按照生产所需时间计算工序计划开工、计划完工时间
    - 计算负荷​：按顺排或均化算法计算资源负载，计算完成后跳转资源负荷报表
    - 修改：可编辑每日产能
    - 显示非瓶颈工序：点击后查看生产订单所有工序
- **下方甘特图功能**
- **单据来源**：生产订单、产能维护
- **单据去向**：调整后的生产订单工序

**【处理流程及业务规则、算法描述】**

- **左树**

**【功能描述】**

资源负荷报表模块用于可视化展示各类资源在指定时间段内的负载情况，支持按日/周/月时格维度分析设备、人员、场地等资源的利用率，提供超负荷预警和产能优化决策支持。

**【功能说明】**

- **业务菜单**：计划排产 -> 报表管理 -> 产能维护
- **业务按钮**：
    - 时间维度切换​：日/周/月
    - 导出报表​：导出Excel格式负荷明细
    - 穿透查询​：跳转关联工序详情
- **单据来源**：细能力计划模块计算的资源排产结果
- **单据去向**：生产计划优化决策依据

## 资源负荷报表

**【功能描述】**

资源负荷报表模块用于可视化展示各类资源在指定时间段内的负载情况，支持按日/周/月时格维度分析设备、人员、场地等资源的利用率，提供超负荷预警和产能优化决策支持。

**【功能说明】**

- **业务菜单**：计划排产 -> 报表管理 -> 产能维护
- **业务按钮**：
    - 时间维度切换​：日/周/月
    - 导出报表​：导出Excel格式负荷明细
    - 穿透查询​：跳转关联工序详情
- **单据来源**：细能力计划模块计算的资源排产结果
- **单据去向**：生产计划优化决策依据

**【用户界面、交互及输入描述】**

**资源负荷报表**

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1wvqreb1PeYG2nak/img/57c9d441-2fea-4736-8f86-720831885913.png)

- 负载率>100% → 自动标红+警示图标

**【处理流程及业务规则、算法描述】**

- **超负荷判断​：**
    - ≥100%：红色警示
    - 90%-99%：黄色预警
    - <90%：绿色正常
- `周负载率(%) = (∑资源当周工序时长 / ∑资源周标准产能) × 100%`
- `月负载率(%) = (∑资源当月工序时长 / ∑资源月标准产能) × 100%`
- 如果表中有数据，则按表里的数据计算标注产能，如果表中当日没有数据，则按资源档案维护的标准产能取数

## 生产订单派工

**【功能描述】**

细能力平衡模拟模块支持在资源约束条件下进行设备级排产，通过动态计算设备负载与工序时长相匹配关系，优化生产订单执行顺序。系统将采用左右分栏结构直观展示订单工序信息与设备占用甘特图。

**【功能说明】**

- **业务菜单**：生产制造 -> 生产管理 -> 生产订单派工
- **业务按钮**：
    - **左区功能​**
        - 生产订单列表
        - 优先规则切换：`预设优先级`/`交货期`/`紧迫系数`
        - 优先级排序：按照排序规则，对生产订单进行排序
        - 修改：可编辑优先级排序
    - **右区功能**​
        - 批量锁定/单行锁定​：锁定所有工序的计划时间
        - 批量解锁/单行解锁​：锁定所有工序的计划时间
        - 生产派工：生成派工单
        - 修改：可编辑每日产能
- **单据来源**：生产订单、产能维护
- **单据去向**：调整后的生产订单工序

**【用户界面、交互及输入描述】**

**【处理流程及业务规则、算法描述】**

- 不计算产能维护
- 支持录入设备、人员、场地，可多选，派工时保存到派工单工序的字段上
