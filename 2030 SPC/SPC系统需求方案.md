概述

_在我们的生产环境中，产品品质的不稳定和生产效率的低下已经成为我们业务发展的主要瓶颈。为了解决这些问题，我们需要一个强大的统计过程控制（_**_SPC_**_）系统来实时监控我们的生产过程，以便我们可以及时识别和解决潜在的问题。_

\_SPC_\_系统是我们实现品质控制和生产效率提升的关键工具。通过实时收集和分析生产数据，\__SPC_\_系统可以让我们了解生产过程的状态，预测可能出现的问题，以及采取必要的措施来解决问题。此外，__SPC_\_系统还可以提供清晰的图形和报告，使我们可以轻松地理解和解释生产数据。_

引言

项目名称

才匠智能-CJC-SPC（CJC-统计过程控制）

项目背景和内容概述

_为了通过实时监控和异常检测，提高生产过程的质量控制和效率提升_

_我们的_\_SPC_\_系统将包括以下主要功能：_

- _数据收集：自动从生产设备中收集数据，包括产量，质量参数等。_
- _数据分析：对收集到的数据进行统计分析，以识别任何异常情况。_
- _图形生成：生成控制图和统计图表，以便更清楚地显示生产状态。_
- _实时监控：实时监控生产过程，以便我们可以及时采取行动。_
- _警报系统：如果检测到异常情况，系统将自动发出警报，以便我们可以迅速采取行动。_

SPC系统任务概述中的业务主线包括：

1. 实时监控生产过程中的异常情况，并及时采取措施；

2. 收集和分析生产数据，以便了解生产过程的状态，预测可能出现的问题，并采取必要的措施；

这些业务主线是SPC系统的核心功能，它们共同构成了一个完整的生产过程控制和改进体系。

名词解释

系统名词

**【SPC】**：\_即统计过程控制（__Statistical Process_ Control），它是一种利用统计方法对生产过程进行实时监控，控制和改进产品质量的过程。SPC强调预防原则，通过对生产过程中的关键数据进行实时收集和分析，及时发现异常情况并采取相应的措施，以避免问题出现

【CAR】：CAR是Corrective Action Request的缩写，意思是纠正措施要求。它是一种用于记录和跟踪质量问题的工具，通常用于工业生产和质量控制领域

【MSA】：MSA是测量系统分析的英文缩写，全称为Measurement Systems Analysis。它是一种通过统计分析的手段，对构成测量系统的各个影响因子进行统计变差分析和研究以得到测量系统是否准确可靠的结论的方法

【FMEA】：效应分析（FMEA，Failure Mode and Effects Analysis）是一种在各行各业都有广泛应用的可用性分析方法，它通过对系统范围内潜在的故障模式加以分析，并按照严重程度进行分类，以确定失效对于系统的最终影响

业务名词

【Xbar-S控制图】：是一种均值标准差控制图，它由两个控制图组成：均值控制图（Xbar）和标准差控制图（s）。这种控制图通常用于变量数据控制，可以非常准确地监测过程的波动，探测过程的变化

【Xbar-R控制图】：一种均值极差控制图，它由两个控制图组成：均值控制图（Xbar）和极差控制图（R）。这种控制图通常用于监测过程的均值和变异，可以非常有效地探测过程中的变化

【I-MR控制图】：一种组合控制图，它包括单值控制图（I图）和移动极差控制图（MR图）。这种控制图主要用于监视过程中的均值和变异情况，可以在连续数据的情况下使用

【NP控制图】：（不良数控制图）是一种用于监测生产过程中不合格品数的控制图。它与P控制图相似，但NP控制图更注重不合格品的数量而不是不合格品与样本的比率

【P控制图】：是一种用于监测生产过程中不合格品率的控制图。它主要用于判断生产过程中的不合格品率是否保持在所要求的统计受控状态。

在P控制图中，数据以点的形式呈现在图上。每个点表示的是在特定抽样规模下，所对应的不合格品的数量。通过观察这些点的分布情况，可以判断过程中的不合格品率是否处于受控状态。P控制图的控制限与抽检总数n关联，由于控制限的计算公式中涉及到抽检总数，因此P控制图的控制限是阶梯形状的，也即每个数据点的控制限会随抽检的样本数n而不同。当数据点超出控制限时，则认为控制图失控

【C控制图】：（缺陷数控制图）是一种计数值控制图，用于监测一定单位内的缺陷数量。它通常用于监测产品在生产过程中的缺陷数，以便更好地控制产品质量

【U控制图】：U控制图是一种计数值控制图，用于监测生产过程中单位产品的不合格品数。它通常用于质量控制和工业过程控制等领域。

在U控制图中，数据以点的形式呈现在图上。每个点表示的是在特定抽样规模下，所对应的单位产品的不合格品数。通过观察这些点的分布情况，可以判断过程中的单位产品不合格品数是否处于受控状态

【柏拉图】：一种数据管理和分析工具，用于识别和显示在生产过程中出现的问题和改进的可能性。它以柱形图的形式呈现，其中柱子的高度表示每个项目或因素的贡献程度，柱子的宽度表示每个项目或因素在生产过程中的频率或发生概率

【箱线图】：一种用作显示一组数据分散情况资料的统计图，它显示了数据的上限、下限、中位数和四分位数。通过观察箱线图，可以快速了解数据的分布情况，包括数据的中位数、数据的分散程度以及异常值的情况。在箱线图中，箱子中间的横线表示数据的中位数，箱子的高度表示了数据的分散程度。箱子的上边缘和下边缘分别表示数据的上限和下限，如果数据超出这个范围，则被认为是异常值。在箱子的上方和下方，各有一条线，它们代表最大最小值。如果有数据点“冒出去”，可以理解为“异常值”

【正态校验】：用于检验一组数据是否符合正态分布。它可以通过计算数据的偏度和峰度系数来进行检验，或者使用图形方法如Q-Q图和直方图来进行观察。在正态校验中，如果数据不符合正态分布，则可能存在异常值或错误数据。对于异常值的处理，可以选择将其删除或进行修正，而对于错误数据的处理，则需要进行调查和纠正

【相关性分析图】：用于展示两个变量之间相关关系的图表。在相关性分析图中，通常会绘制散点图和趋势线，以展示变量之间的趋势和关系。散点图是一种简单的图形，用于展示两个变量之间的关系。在散点图中，每个点表示一对观测值，点的位置由两个变量的值决定。通过观察散点图，可以大致了解两个变量之间的关系是正相关还是负相关，以及它们之间的强度和方向

function calculateStandardDeviation(array) {  

    let avg = array.reduce((a, b) => a + b) / array.length;  

    let variance = array.reduce((variance, value) => {  

        let diff = value - avg;  

        return variance + diff \* diff;  

    }, 0) / array.length;  

    return Math.sqrt(variance);

function normdist(x, mean, standard_dev, cumulative) {

function calculateCPK(mu, sigma, specMin, specMax) {

箱线图

【描述】：用来表示一组或多组连续型数据分布的中心位置和散布范围的图形。在箱线图中，箱子的中间一条线，是数据的中位数，代表了样本数据的平均水平。箱子的上下限，分别是数据的上四分位数和下四分位数，这意味着箱子包含了50%的数据。箱子的高度在一定程度上反映了数据的波动程度。在箱子的上方和下方，各有一条线，代表最大最小值。有时候会有一些点“冒出去”，可以理解成“异常值”。这些异常值可以通过比较与箱线图的上下触须和四分位数差（IQR）来确定。大于上四分位数1.5倍四分位数差的值，或者小于下四分位数1.5倍四分位数差的值，通常被划为异常值

计量值GRR分析

【描述】：计量值GRR分析是一种评估测量系统变差的方法，通过计算GRR（测量重复性和测量再现性）来评估测量系统的准确性和可靠性。

在计量值GRR分析中，GRR可以通过重复测量和再现测量两个方面的数据来计算。重复测量是指对同一被测对象进行多次测量的变差，而再现测量是指不同测量人员在相同条件下对同一被测对象进行测量的变差。

通过计算GRR，可以评估测量系统的稳定性和可靠性。如果GRR较小，说明测量系统的变差较小，测量结果较为准确可靠；如果GRR较大，说明测量系统的变差较大，测量结果可能存在较大的误差

function DEVSQ(data) {  

    let sum = 0;  

    for (let i = 0; i < data.length; i++) {  

        sum += Math.pow(data\[i\] - data.mean(), 2);  

    }  

    return sum;  

}

function FINV(probability, degrees_freedom1, degrees_freedom2) {  

    // 首先检查输入值的合理性  

    if (probability &lt; 0 || probability &gt; 1) {  

        return "Probability must be between 0 and 1";  

    }  

    if (degrees_freedom1 <= 0 || degrees_freedom2 <= 0) {  

        return "Degrees of freedom must be greater than 0";  

    }  

    // 使用一个简单的迭代方法来逼近 FINV 的值  

    let x = 0.5; // 初始猜测值  

    const epsilon = 0.00001; // 定义精度  

    const maxIterations = 1000; // 最大迭代次数  

    for (let i = 0; i < maxIterations; i++) {  

        const fDist = (1 / probability - 1) \* (degrees_freedom2 / degrees_freedom1);  

        const newX = (x \* degrees_freedom2 + degrees_freedom1 \* fDist) / (degrees_freedom2 + x \* fDist);  

        if (Math.abs(newX - x) < epsilon) {  

            return newX;  

        }  

        x = newX;  

    }  

    return "Maximum iterations exceeded"; // 如果迭代次数超过最大值，返回错误消息  

}

function FDIST(x, df1, df2) {  

  // 计算F分布的概率密度函数  

  const n1 = df1;  

  const n2 = df2;  

  const x2 = Math.pow(x, 2);  

  const a = (n1 \* n2) / (n1 + n2);  

  const b = n1 \* n2 / (n1 + n2);  

  const c = (n1 \* n2) / (n1 + n2);  

  const d = Math.pow(x2, a - 2) \* Math.pow(c, b - 2);  

  const fDist = 1 / (Math.pow(2, a - 1) \* Math.gamma(b - 1)) \* d \* Math.pow(x, a - 3) \* Math.exp(-(x2 / 2));  

  return fDist;  

}

计数Kappa分析

【描述】：计数Kappa分析是一种统计方法，用于评估两个或多个观察者之间的一致性程度。它通常用于评估分类任务或评级任务的一致性，例如医学诊断、图像识别、文本分类等。在计数Kappa分析中，观察者对同一组样本进行分类或评级，然后计算每个观察者之间的分类或评级一致性。Kappa系数是这些一致性程度的平均值，它表示观察者之间的一致性相对于随机一致性的程度。Kappa系数的值范围在-1到1之间，其中1表示完全一致，0表示随机一致，-1表示完全不一致。通常，Kappa系数大于0.75被认为是高度一致的。计数Kappa分析的优点是它可以处理多个观察者的情况，并且可以处理不同的分类或评级标准。此外，它还可以处理不均衡的分类或评级情况，例如某些类别或评级的样本数量比其他类别或评级多

小样法GRR分析

【描述】：小样法GRR分析是一种通过小样测试来评估测量系统变差的方法。这种方法通过收集小样数据，并利用统计工具进行分析，以评估测量系统的准确性和可靠性。在小样法GRR分析中，首先需要收集一定数量的小样数据，这些数据可以来自同一批次的产品或不同的批次。然后，利用统计工具对小样数据进行处理和分析，以计算GRR（测量重复性和测量再现性）值。GRR值反映了测量系统的变差情况，如果GRR值较小，说明测量系统的变差较小，测量结果较为准确可靠；如果GRR值较大，说明测量系统的变差较大，测量结果可能存在较大的误差。

计数型对比分析

【描述】：计数型对比分析是一种统计分析方法，用于比较两组或多组计数数据之间的差异。这种方法通常用于评估不同组之间的频率、比例或率等指标，并确定这些指标之间是否存在显著差异。

在进行计数型对比分析时，首先需要收集两组或多组计数数据，例如两个不同治疗组的患者人数、两个不同产品的缺陷数量等。然后，选择合适的统计方法对数据进行分析和比较。

常用的计数型对比分析方法包括卡方检验、Fisher确切概率法等。卡方检验是一种用于比较两个或多个分类变量之间关系的统计方法，适用于大样本数据。而Fisher确切概率法适用于小样本数据，可以直接计算两组计数数据之间的显著差异

线性偏倚分析

【描述】：线性偏倚分析是一种测量系统分析方法，用于评估测量系统的准确性和线性度。线性偏倚表示测量值与实际值之间的差异，而线性度则表示操作范围内多个独立偏差误差的相关性。

在进行线性偏倚分析时，通常选择多个具有代表性的样品，测量它们的实际值，并记录每个样品的测量结果。然后，根据这些结果计算偏倚和线性度。

偏倚的计算方法是：对于每个样品，将测量平均值与参考值之间的差异计算出来，然后将这些差异的平均值作为偏倚。如果偏倚较大，则说明测量系统存在系统性的误差。

效应分析（FMEA）V2.3

![图片 271](files/0192c7de-028e-7dda-89cf-615063cb911d/ignore-error,1)

FMEA 潜在失效模式与后果分析（Failure Mode and Effects Analysis）是:在产品/过程/服务等的策划设计阶段，对构成产品的各子系统、零部件，对构成过程，服务的各个程序逐一进行分析，找出潜在的失效模式，分析其可能的后果，评估其风险，从而预先采取措施，减少失效模式的严重程序，降低其可能发生的概率，以有效地提高质量与可靠性，确保顾客满意的系统化活动

FMEA根据产品故障可能产生的环节：设计、制造过程、使用、[承包商](https://baike.baidu.com/item/%E6%89%BF%E5%8C%85%E5%95%86/5894462?fromModule=lemma_inlink)（供应商）以及服务可细分为：

1.  DFMEA（设计FMEA）：
    1.  分析对象：产品设计。
    2.  关注焦点：在设计阶段，识别产品的潜在失效模式，并评估这些失效模式在后续生产过程中可能对产品质量、安全和功能造成的影响。
    3.  应用场景：新产品开发或产品改进过程中，帮助设计团队识别并预防潜在的设计问题。
2.  PFMEA（过程FMEA）：
    1.  分析对象：生产过程。
    2.  关注焦点：在生产过程中，识别可能导致产品缺陷或不良的操作步骤，并评估这些操作步骤对产品质量的影响。
    3.  应用场景：生产流程改进或新生产线引入时，帮助生产团队识别并预防潜在的生产过程问题。
3.  EFMEA（设备FMEA）：
    1.  分析对象：生产设备、工具和夹具。
    2.  关注焦点：评估设备、工具和夹具的潜在失效模式，以及这些失效模式对产品质量和生产效率的影响。
    3.  应用场景：设备维护、故障排除或新设备引入时，帮助设备团队识别并预防潜在的设备问题。
4.  SFMEA（体系FMEA）：
    1.  分析对象：整个生产或服务体系。
    2.  关注焦点：评估整个生产或服务体系中可能出现的失效模式，以及这些失效模式对产品质量、交货期、成本和客户满意度的影响。
    3.  应用场景：企业战略调整、组织结构变革或业务流程优化时，帮助企业识别并预防潜在的体系问题

\*\*实验设计（DOE）\*\*V2.4

一种基于统计学的质量管理工具，其原理对于没有数理统计基础的人来说，比较难以理解掌握。但是，通过控制图、故障分析、因果分析、失效分析、能力分析等工具的运用，或者是直接实际工作的反映，会得出一些关键的问题点，它反映了某个指标或参数不能满足需求，但是针对这样的问题，可能运用一些简单的方法根本就无法解决，这时候可能就会想到试验设计。

在SPC实验设计DOE中，可以通过控制关键过程输入变量（KPIV），得到关键过程输出变量（KPOV），正中目标。例如，在生产制造过程中，通过DOE优化设计过程的温度、湿度、压力、时间、速度、加工尺寸、冷却方式、成分含量等过程输入参数，实现了期待的过程输出的结果，同时提升了生产线的产品质量或产量，降低了制造成本。

试验设计方法是一种同时研究多个输入因素对输出的影响的方法。它是指通过对选定的输入因素进行精确、系统的人为调整来观察输出变量的变化情况，并通过对不同结果的分析，最终确定影响结果的关键因素及其最有利于结果的因素取值的方法。

田口设计直交表

【描述】：田口设计直交表是一种实验设计方法，用于进行正交试验。直交表是田口方法的基础，是一种方阵表格，由正交拉丁方阵和正交补拉丁方阵构成。

直交表的特点是具有均衡性、正交性和同类型因子数相等。它适用于多因子多水平的试验，可以有效地减少试验次数，提高试验效率。

在田口设计中，通常会使用直交表进行正交试验，以确定各个因子对响应变量的效应。通过选择合适的直交表和实验水平，可以快速地找到对响应变量影响最大的因子和其最优水平组合

例如，某种试验需安排的4个因素，而每个因素又分3个水平做试验可选择的正交表L9(34)。L表示正交表的符号，9表示按此表要做9次试验，3表示每个因素有3个水平，4表示最多能安排4个因素。

田口式稳健设计

【描述】：稳健设计的基本思想是把产品的稳健性设计到产品和制造过程中，通过控制源头质量来抵御大量的下游生产或顾客使用中的噪声或不可控因素的干扰，这些因素包括环境湿度、材料老化、制造误差、零件间的波动等等

稳健性设计的功效在于帮助设计人员找到一组最佳的产品或工艺设计参数，使产品在最低廉的成本条件下(或最宽松的工艺条件下)，达到输出性能最高地稳健性。

稳健性(robustness),也叫鲁棒性，是指因素状况发生微小变差对因变量影响的不敏感性。换句话说，产品性能与某个因素有关，因素状态变化时，产品的性能也随之变化。如果因素状态的变化对产品性能的影响不大，我们就说产品性能对该因素的变化是不敏感的，又称是稳健性的，或说产品性能对该因素的变化具有稳健性。

外噪声:由于环境因素和使用条件的波动或变化，引起质量特性值的波动例如，温度、湿度、位置等

内噪声:由于在储存或使用过程中随着时间的推移，发生材料变质、劣化现象而引起质量特性值的波动。例如，电器产品绝缘材料的老化等

产品间噪声 : 在相同生产条件下生产制造出来的一批产品，由于人、机料、法、环的变化，引起质量特性值的波动。
