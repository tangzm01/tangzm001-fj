# （已确认）抽样方案-3.6.0-PRD

**功能概述**

问题来源：产品功能补充

业务概述：在生产过程中，为了确保产品质量，需要对生产出的产品进行抽样检验。质检方案会根据不同的抽样方案确定需要抽检的样本数量。抽样方案包括全检和抽检，抽检又分为按固定数量检、按比例检和按国标检。此需求方案旨在详细描述如何根据报检数量和质检方案中的抽样方案来计算对应的样本数量

**用户使用旅程**

- 点击质量管理－>质检方案按钮，进入质检方案设置画面。具体步骤如下所示：
    - 第1步：点击质检方案进入质检方案画面后可以新增一个质检方案；如果已经存在了一个质检方案，可以参照输入，增加一个已存在质检方案的新版本；
    - 第2步：确定质检方案的抽样层次；
    - 第3步:确定质检方案的抽样方案、检验水平、AQL值、调整规则，如果抽样层次为按方案控制，就在方案上定义这些值，如果按步骤控制就在步骤上定义，如果在指标上控制就在指标上定义；
    - 第4步：定义质检成本计算方法；
    - 第5步：定义质检方案的有效期；
    - 第6步：定义质检方案的步骤，一个质检步骤可以有多个追加步骤，当该步骤不合格时　再进行追加步骤的检验（当选择了步骤后，系统会将该步骤下的指标、追加指标、指标值自动带入，可以修改）；
    - 第7步：定义每个步骤下的质检指标，一个指标可以定义多个追加指标，当指标不合格时再进行追加指标的检验；
    - 第8步：定义每个指标的指标值；
    - 第9步：保存质检方案。

**抽样方案**

【说明】：基础现有抽检方案进行改造

【功能描述】：

- 按照国标系统预置一般抽检方案，且不可删除，不支持修改。增加系统预置字段，页面不显示，仅系统预置的标准抽检方案该字段为是，其他均为否
- 抽样方式：全检，按标准抽检，自定义抽检，按比例抽检
    - 全检：抽检明细数据不支持维护，表格为禁用状态，

- 按标准抽检：选择按标准抽检时，抽检明细可编辑，如果勾选全检则AQL，第N次抽样，抽样数量，AC，RE输入框值清空，检验水平默认一般，严格程度默认正常。且以上字段不支持输入

- 自定义抽检：选择自定义抽检时，抽检明细和编辑，如果勾选全检则AQL，第N次抽样，抽样数量，AC，RE输入框值清空，检验水平默认一般，严格程度默认正常。且以上字段不支持输入

- 按比例抽检：选择按比例抽检时，抽检明细可编辑，且明细列表仅显示：序号，起始批量，终止批量，全检，抽样比例，如果勾选全检，则抽样比例清空且不支持输入

- 填写AC值和RE值时，AC值必须小于RE值
- 抽样方案为按标准或自定义抽检时，表头标准类型和抽检次数都是必输的
- 相同检验水平和严格程度一致时当抽样明细的第n次抽样小于抽检次数时，AC与RE不能连续，（抽检次数2，第n次抽检为1，此时AC为5，RE不能为6，必须大于6）
- 相同检验水平和严格程度一致时抽样方案行的起始批量和终止批量必须连续，AQL的值必须逐步增加（例如：10行AQL值为1.0，20的AQL值必须大于1.0）
- 检验水平和严格程度一致时抽样方案行的终止批量和起始批量必须连续（例如10行起始为100，终止为200，则20行的起始必须大于200）
- 如果勾选全检则AQL，第N次抽样，抽样数量，AC，RE输入框值清空，检验水平默认一般，严格程度默认正常。且以上字段不支持输入

**质检方案**

【说明】：基于现有功能完善抽检方案相关变更，质检数量根据匹配对应的抽检方案计算

【功能描述】：

- 字段补充：检查质检方案，方案下的步骤，步骤下的指标对应表格结果是否包含：抽样方案，检验水平，AQL值，如若不包含请添加对应字段。且结合以下需求实现新增修改功能。
- 抽样层次 ： 方案
    - 新增修改质检方案时，抽样层次选择方案，且对应抽样方案的抽样方式为自定义抽检或按标准抽检，则方案上的抽样方案，检验水平，AQL值必填，若对应抽样方案的抽检方式为全检或按比例抽检，则检验水平，AQL值清空且禁用。
    - 步骤和指标上的抽样方案不支持填写为禁用状态。
- 抽样层级：步骤
    - 新增修改质检方案时，抽样层次选择步骤，则方案和指标上的抽样方案，检验水平，AQL不支持填写为禁用状态。
    - 若步骤上的抽样方案的抽样方式为自定义抽检或按标准抽检，则步骤上的抽样方案，检验水平，AQL值必填，若抽样方案的抽检方式为全检或按比例抽检，则检验水平，AQL值清空且禁用。
- 抽样层级：指标
    - 新增修改质检方案时，抽样层次选择指标，则方案和步骤上的抽样方案，检验水平，AQL不支持填写为禁用状态。
    - 若指标上的抽样方案的抽样方式为自定义抽检或按标准抽检，则指标上的抽样方案，检验水平，AQL值必填，若抽样方案的抽检方式为全检或按比例抽检，则检验水平，AQL值清空且禁用。
- 指标下的指标值：增加对应判定标准字段，按照判定标准匹配基础档案中的质检指标下指标值信息，拉取的指标值信息可进行修改，但判定标准需保持一致。指标值中支持维护多行，但相同质量标准下的比较值不允许重叠，例如：比较符为>指标值为6，则不允许存在比较符为>指标值为8，比较符为between指标值上限必须大于6等校验，
- 支持主子表同时新增，编辑。皆需满足以上逻辑
- 步骤支持复制可选择已维护好的质检方案下的步骤进行新增，自动带出对应选择步骤下的指标和指标值

**质检单**

【说明】：基于现有工序质检进行功能补充

【功能描述】：

- 抽取数量计算：
    - 全检：抽样数量 = 质检数量
    - 按标准抽检：抽样数量 = 质检数量匹配范围根据AQL值和检验水平查找方案绑定的抽样方案上的抽样数量
    - 按比例抽检：抽样数量 = 质检数量匹配范围获取比例 \* 质检数量（若对应行勾选全检，则抽样数量 = 质检数量）
    - 自定义抽检：抽样数量 = 质检数量匹配范围根据AQL值和检验水平查找方案绑定的抽样方案上的抽样数量（若对应行勾选全检，则抽样数量 = 质检数量）
    - 抽样数量按比例抽取如果是小数，需要按照单位对应的精度进行取值
- 抽样层次：
    - 方案：方案下所有指标的抽取数量一致
    - 步骤：方案下相同步骤的指标抽取数量一致
    - 指标：方案下指标抽取数量可不一致，根据抽取数量计算公式计算
- 质检结果
    - 指标：
        - 全检：不合格时指标结果为不合格，如果指标质量判异为是，则指标步骤结果为不合格
        - 按标准抽检：不合格时指标结果为不合格，不合格数量小于AC值时，步骤结果为合格。不合格数量大于RE值时，质检步骤结果为不合格。若指标质量判异为是，则指标不合格则指标步骤为不合格。
        - 按比例抽检：不合格时指标结果为不合格，如果指标质量判异为是，则指标步骤结果为不合格
        - 自定义抽检：不合格时指标结果为不合格，不合格数量小于AC值时，步骤结果为合格。不合格数量大于RE值时，质检步骤结果为不合格。若指标质量判异为是，则指标不合格则指标步骤为不合格。
