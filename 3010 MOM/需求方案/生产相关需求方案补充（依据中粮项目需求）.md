# 生产相关需求方案补充（依据中粮项目需求）

## 1.工艺路线

原始要求：需要支持维护默认班组、设备、产线、是否需要质检、是否需要投料等信息

系统改造：

- 工艺路线工序添加设备，产线字段，班组及是否需要质检，是否需要投料字段以存在，可直接使用
- 工艺路线新增时添加以上字段显示且支持修改，工艺路线选择产线后自动带入到工艺路线下的工序上
- 支持，修改，编辑操作以及页面展示字段皆需添加以上字段，包含列表
- 后续工序触发工序质检时根据对应的是否需要进行校验，配置为是则推送报检单，若配置为否则不进行推送
- 以上添加的字段在创建生产订单生成对应的工序信息时需要同步带入，后续相关操作也需要同步带入
- 检查生产订单工序是否存在相关字段，若不存在，则需要进行同步添加。对应字段需要在页面上显示
- 检查派工单工序是否存在相关字段，若不存在，则需要进行同步添加。对应字段需要在页面上显示

## 3.设备档案

### 关键数据项

| 数据项 | 字段名 | 数据类型 | 必填  | 说明  |
| --- | --- | --- | --- | --- |
| 设备  | em_id | 关联字段 | 是   | 关联设备主档，单选，展示设备编码+名称 |
| 标准产能 | standard_capacity | 数值  | 是   | 设备的标准产出能力，支持小数，精度2位 |
| 单位  | unit | 枚举/关联 | 是   | 产能计量单位，如：件、kg、吨、批次等 |
| 每批产能 |     |     | 是   |     |
| 每日固定加工批次 | daily_batches | 整数  | 是   | 设备每日可执行的加工批次数量，默认为空表示不限制 |
| 每批可加工位置 | positions_per_batch | 整数  | 是   | 每批次可同时加工的位置/工位数量，默认为空表示不适用 |

### 功能说明

设备档案改造：添加字段

- `furnace_count` (INT)：炉口数量，如 3
- `furnace_desc` (nvarchar)：炉口属性,绑定对应枚举，枚举维护内外
- `max_batch_size` (INT)：每次最大可生产炉数，如 2
- 支持新增修改，非必填，每次最大可生产炉数维护时数值不能大于炉口数量

以下功能添加菜单实现：

- 一个设备只能有一条产能档案（设备维度唯一性）
- 标准产能必须大于0
- 每日固定加工批次 > 0 时，每批可加工位置也需 > 0，否则无意义
- 设备状态变更（如停用）时，可联动更新产能档案状态
- 删除设备时，需校验产能档案是否被生产订单等业务引用 （2026-06-05 先不校验吧，目前平台校验不了 胡）

### 功能清单

| 功能模块 | 功能点 | 优先级 | 说明  |
| --- | --- | --- | --- |
| 数据录入 | 新增产能档案 | P0  | 核心功能 |
|     | 编辑产能档案 | P0  | 核心功能 |
|     | 删除产能档案 | P1  | 需校验引用关系 |
|     | 批量导入 | P2  | Excel导入，支持初始化场景 |
| 数据查询 | 列表查询 | P0  | 支持多条件筛选、排序、分页 |
|     | 详情查看 | P0  | 展示完整信息 |
|     | 导出功能 | P2  | Excel导出 |
| 数据校验 | 唯一性校验 | P0  | 设备维度唯一 |
|     | 关联完整性校验 | P0  | 设备必须存在且有效 |
| 状态管理 | 启用/停用 | P1  | 停用后不参与排程计算 |

### **校验规则**

| 校验项 | 校验规则 | 错误提示 |
| --- | --- | --- |
| 设备必填 | em_id 不能为空 | 请选择设备 |
| 设备唯一性 | 同一设备不能重复建档 | 该设备已存在产能档案，请勿重复添加 |
| 标准产能必填 | standard_capacity 不能为空 | 请输入标准产能 |
| 标准产能 > 0 | standard_capacity > 0 | 标准产能必须大于0 |
| 单位必填 | unit 不能为空 | 请选择单位 |
| 批次与位置联动 | daily_batches > 0 时，positions_per_batch 也应 > 0 | 已设置每日批次，请补充每批可加工位置 |

### 列表查询

**查询条件：**

- 设备编码/名称（模糊搜索）
- 单位
- 状态（启用/停用/全部）
- 创建时间范围

**列表字段：**

| 字段  | 是否展示 | 排序支持 |
| --- | --- | --- |
| 设备编码 | 是   | 是   |
| 设备名称 | 是   | 是   |
| 标准产能 | 是（计算列，可自行修改） | 是   |
| 单位  | 是   | 是   |
| 每日固定加工批次 | 是   | 否   |
| 每批可加工位置 | 是   | 否   |
| 每批产能 | 是   | 是   |
| 状态  | 是   | 是   |
| 更新时间 | 是   | 是   |
| 操作  | 是   | \-  |

**计算列说明：**

```
标准产能 = 每批产能 × 每日固定加工批次 × 每批可加工位置
（若批次或位置为空，则不计算，显示 "-"。）
```

### 验收标准

| 序号  | 验收项 | 验收标准 |
| --- | --- | --- |
| 1   | 新增功能 | 可成功新增产能档案，校验规则生效 |
| 2   | 唯一性校验 | 同一设备重复新增时提示错误 |
| 3   | 编辑功能 | 可编辑除设备外的所有字段 |
| 4   | 查询功能 | 支持多条件筛选，结果正确 |
| 5   | 删除功能 | 删除成功，已引用数据给出提示 |
| 6   | 启用/停用 | 状态切换正常，停用数据不参与业务计算 |
| 7   | 导入导出 | Excel格式正确，数据完整 |

## 4.工序组合单

### 关键数据项

与对应下料排产计划中的关键数据项一致

### 功能说明

- 查询
    - 支持按照查询条件查询
- 打印
    - 支持打印工序组合单，及工序标签
- 删除&批量删除
    - 工序组合单支持进行删除及批量删除
    - 仅开立状态的支持进行删除，主表开立状态删除时需要校验子表下是否存在非开立状态的，如果存在则不支持删除
    - 组合单工序开立状态的支持删除及批量删除
