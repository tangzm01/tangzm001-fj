## 1.原始需求描述

生产同种产品时，不同工序可使用不同的设备或工具进行生产，在设定对应产品的工艺路线时需要先拟定默认生产的设备和工具，依据此产生新的需求。

1.  设备绑定：在实际生产中，一个工序可能由一台设备完成，也可能需要多台设备协同完成。但通常，在工艺路线中，一个工序通常对应一个主要设备（或工作中心）。然而，有时一个工序可能需要多个设备，比如先在一台设备上加工，然后立即在同一工序内的另一台设备上处理（但这种情况有时会被拆分成两个工序）。因此，是否需要绑定多个设备取决于业务场景和工序的粒度。
2.  工具绑定：工具可能包括夹具、模具、刀具、量具等。一个工序很可能需要多个工具，比如加工一个零件可能需要夹具、刀具和量具。因此，工具绑定多个是比较常见的

## 2.产品功能实现

### 2.1工艺路线调整

**关键数据项**

添加表用来存储工序及工具对应关系

| 字段编码 | 字段名称 | 字段类型 | 必填  | 默认值规则 | 说明  |
| --- | --- | --- | --- | --- | --- |
| tool_em_id | 工具设备 | 字符串 | 否   | 所选设备ID |     |
| routing_Id | 工艺路线ID | 字符串 | 否   |     |     |
| operation_id | 工序信息 | 字符串 | 否   |     |     |
| em_category_Id | 设备分类 | 字符串 | 否   | 根据选择设备ID带出 |     |
| theType | 资产分类 | 枚举  | 否   | 根据选择设备ID带出 | 与设备分类共用枚举 |
| emGroup_Id | 设备组 | 字符串 | 否   | 根据选择设备ID带出 |     |

**功能说明**

![](files/019facac-705d-77fd-8cf8-0d7e809de998/image.png)![](files/019facac-705d-77fd-8cf8-1223df6b79e8/image.png)

- 工艺路线工序表添加设备（em_id）及工具（tool_em_id）字段
- 工艺路线维护增加设备和工具维护，设备仅支持单选操作，（默认查询设备分类中资产分类为机器设备类型的设备信息，支持手动修改条件），工具支持多选，（默认查询设备分类中资产分类为模具设备和工装设备类型的设备信息，支持手动修改条件），保存时按照多选工具信息进行将工具信息存储至工序工具对照表中，
- 工具的新增通过工艺路线工序上的选择工具实现，二次新增及后续修改及删除通过工具页面对应按钮实现，新增时需单独处理工艺路线信息是的工具信息时，后续工艺路线修改将对应选择工具信息进行隐藏，不额外处理工具信息。如需变更使用工具页签的相关按钮实现

### 2.2生产订单

**关键数据项**

添加表用来存储工序及工具对应关系

| 字段编码 | 字段名称 | 字段类型 | 必填  | 默认值规则 | 说明  |
| --- | --- | --- | --- | --- | --- |
| mo_id | 生产订单 | 字符串 | 否   |     |     |
| momoperatio_id | 生产工序 | 字符串 | 否   |     |     |
| tool_em_id | 工具设备 | 字符串 | 否   | 所选设备ID |     |
| routing_Id | 工艺路线ID | 字符串 | 否   |     |     |
| operation_id | 工序信息 | 字符串 | 否   |     |     |
| em_category_Id | 设备分类 | 字符串 | 否   | 根据选择设备ID带出 |     |
| theType | 资产分类 | 枚举  | 否   | 根据选择设备ID带出 | 与设备分类共用枚举 |
| emGroup_Id | 设备组 | 字符串 | 否   | 根据选择设备ID带出 |     |

**功能说明**

- 生产订单中的生产工序添加设备
- 添加生产工序工具关系表
- 生产订单新增时按照选择的工艺路线信息生产对应的生产工序设备及生产工序工具关联表
- 若生产订单为其他系统同步过来的则在订单确认时进行加载设备及生产工序工具信息

![](files/019facac-705d-77fd-8cf8-15ec724ea292/image.png)

- 生产订单一键派工或批量派工时根据对应生产订单下的工序工具关系信息生成对应派工单下的工序工具关系表信息
- 生产订单单批派工时进行改造
    - 单批派工添加工序信息显示，仅支持单生产订单进行派工，工序信息支持维护设备，班组，工作中心，计划开工时间，计划完工时间
    - 派工信息支持填写生产批号，派工数量，计划开工日，计划完工日，产线，备注
    - 点击保存时将对应填写的派工信息带入至生成的派工单上，对应的工序信息带入到对应派工单工序信息中，将对应生产订单工序工具信息同步生成至对应的派工单工序工具表中![](files/019facac-705e-73cc-87b2-0d76317588fe/image.png)![](files/019facac-705e-73cc-87b2-116410b6cba4/image.png)
