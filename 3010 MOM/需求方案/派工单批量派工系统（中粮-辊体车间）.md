# 派工单批量派工系统（中粮-辊体车间）

## 一、产品概述

### 1.1 产品定位

本系统为制造企业提供派工单批量派工管理功能，支持将生产订单的各工序派工单快速分配到具体设备和班组人员，实现生产资源的优化配置。

### 1.2 核心价值

- **提升派工效率**: 通过拖拽批量操作，快速完成派工单分配
- **可视化排产**: 按设备、批次、日期多维度展示排产情况
- **灵活调度**: 支持按日期范围、物料、工序等多条件筛选和调度
- **实时反馈**: 产能预警、数量校验、工序顺序校验等实时提示

### 3.1 左侧：派工单列表

![](files/019facac-72b7-70aa-8ff3-078e28b0cb48/image.png)

#### 3.1.1 标题栏

- **标题文本**: "待排订单"
- **图标**: 勾选框 SVG 图标
- **提示信息**: "拖动卡片到右侧'待分配'格子"**位置**: 右侧

#### 3.1.4 订单卡片列表

**卡片数据结构**（一张卡片 = 一个订单的一个工序）:

- **状态：**当前派工单工序的状态，例如“开立”，遵循派工单工序的系统预置档案显示
- **产成品料号品名**: 如 "LP-0001 辊体101"
- **工序信息**: 工序号 + 工序类型 + 工序名称
    - 工序类型标签：标准（绿色）、返工（橙色）、外协（紫色）
- **客户信息**: 如 "神华集团"
- **生产订单号**: 如 "MO-0001"
- **派工单号**: 如 "PG260430-001"
- **工序数量**: 如 "50 PCS"
- **已派**：工序记录的已派数量+拖入右侧的数量累计，需要根据页面效果实时计算
- **计划开工日期**: 如 "2026-05-02"

**卡片交互**:

1.  **拖拽操作**:
    - 鼠标悬停显示"抓取"光标
    - 拖拽中卡片半透明 + 微旋转效果
    - 拖到右侧"待分配"格子时，格子高亮绿色边框
    - 释放后完成派工，卡片出现在右侧对应位置
2.  **已派工订单隐藏**:
    - 已派数量大于等于订单数量时，派工的订单卡片自动从左侧列表隐藏
    - 避免重复派工

### 3.2 右侧：设备+炉次排产区

![](files/019facac-72b7-70aa-8ff3-09cce9344bb0/image.png)

#### 3.2.1 时间轴

**功能**: 按日期切换排产视图，若对应当天有已排信息，需要将对应已排信息默认加载至对应的数据列表上，默认显示当天，按钮找日期切换切换时需要进行查询

**布局**:

- **左箭头**: 时间轴左移（显示更早日期）
- **日期单元格**: 显示"星期 日期"（如 "周四 04-09"）
- **右箭头**: 时间轴右移（显示更晚日期）

**日期单元格状态**:

1.  **默认状态**: 浅灰背景
2.  **选中状态**: 浅绿背景 + 底部绿色短下划线
3.  **今日标识**: 橙色左上角"今"徽标
4.  **区间选择**: 支持选择日期范围，区间内日期浅绿背景

**视图模式切换**:

- **单日视图**: 时间轴显示选中的单日
- **多日视图（2-3天）**: 横向分栏，每天一栏
- **紧凑视图（>3天）**: 卡片压缩显示，只显示关键信息

#### 3.2.2 设备信息

**设备信息展示**:

- **设备编码**: 如 "GL-001"（显示在左侧设备卡），选择对应设备信息渲染（中粮可配置个性化模版默认显示某设备信息）
- **设备名称**: 如 "1号智能炉"
- **产能信息**：产能信息根据对应的设备匹配设备简易产能表，获取对应的标准产能，每日固定加工批次，加工位置，每批产能
    - 已用产能 / 标准产能（如 "0 / 80 PCS"）
    - 产能进度条（绿色表示正常，橙色表示警告，红色表示超限）
- **炉次信息：**炉次信息按照对应设备档案维护的炉口数量显示，其显示的内外选择通过对应的炉口属性绑定的枚举显示
    - 保存派工时需要将对应的选择的炉口位置及内外信息存储至对应的工序组合单上，可使用JSON存储在备注中
    - 炉口选择是需要根据设备维护的最大可生产路数校验，选择炉数不能超过基础档案配置的值
    - 个性化校验：对应炉口选择的炉口属性互斥，不能选择成一样的

**设备卡样式**:

- 浅绿色渐变背景
- 设备编码加粗显示
- 产能信息显示在底部

#### 3.2.3 批次号列

**功能**: 显示该设备下的批次号，批次号自动生成，按照当前设备简易产能配置的每日固定加工批次，渲染对应的产能批次，并且支持添加和删除批次号列，若对应派工单工序拖动到当前批次号列，则自动将派工单工序进行拆分当前批次号列皆有当前派工单工序，根据对应的可派数量进行拆分，可派数量/每批产能 = 需要拆分的单数+余数订单，若超过当前双设备数量，则最大拆分单数为对应的加工位置

- **标签**: "批次号"，批次号自动生成，有当前的日期+流水号，示例：**26060201，26060202，26060203，26060204**
- **批次号胶囊**:
    - 已分配批次：绿色背景 + 深绿文字
    - ~~未分配批次：虚线边框 + 灰色文字（显示"—"）~~

**交互**:

- 同一设备可对应多个批次号，显示几个批次由对应的设备简易产能配置的每日固定加工批次决定，批次支持添加删除

**3.2.4 设备位置**

**功能**：

- 现在该设备下有几个加工位置，根据对应的设备简易产能中维护的加工位置决定，不支持进行调整
- 若对应的派工单工序拖动到当前还是设备位置上，则根据可派数量进行拆分，当前设备位置整行显示对应的派工单工序信息

**布局**

- **标签**：设备位置1-N，累加

**交互**

- 同一设备可对应多个批次号

#### 3.2.5 派工卡片

**卡片状态**:

1.  **空卡槽**:
    - 虚线边框
    - 显示"— 待分配 —"，当天当批次默认展示四个卡片，若超出四个，则往下一行叠加
    - 可拖入派工单工序，拖入派工单的数量需要按照对应设备简易产能每批可加工位置拖入，示例：如果设备简易产能对应的每次可加工位置为4，则对应派工单工序拖入后默认一拆四，对应的数量展示为每批产能展示的数量
2.  **已分配卡片**:
    - 绿色左边框
    - 显示工序名称、规格、排产数量、班组/人员信息
    - 可拖拽调整或撤销派工
3.  **错误卡片**:
    - 红色左边框
    - 显示错误信息（如数量超出、工序顺序错误等）

**卡片信息层级**（精简显示，悬浮显示完整信息）:

1.  **第一行**: 工序名称（加粗）
2.  **第二行**: 规格（带图标前缀）
3.  **第三行**: 排产数量（绿色加粗）+ 单位
4.  **底部**: 班组选择 + 人员选择 + 模具选择

**悬浮提示**:

- 鼠标悬停显示完整信息
- 显示字段：工序号、订单号、物料名称、规格、排产数量、班组、人员等
- 白色背景浮层，带阴影，显示在最上层

**可编辑字段**:

- **排产数量**: 可手动修改，实时校验是否超出上游工序总量，默认数量为当前设备简易产能中维护的每批产能数据
- **班组选择**: 选择框选择班组
- **人员选择**: 选择班组后只能选择班组对应的人员

#### 3.2.6 网格布局

**布局规则**:

- **默认**: 4列网格（grid-template-columns: repeat(4, minmax(0, 1fr))）
- **多日视图**: 横向分栏，每天一栏，每栏内4列网格
- **紧凑视图**: 横向滚动，每天一列，卡片高度压缩至24px

**卡片排列**:

- 已分配的卡片优先排列在前
- 空卡槽排列在后
- 超出4个的卡片自动折叠，点击"展开更多"显示

### 3.3 底部操作栏

#### 3.3.1 按钮组（靠右对齐）

1.  **\[批量修改\]** 按钮:
    - 图标 + 文字
    - 点击打批量修改弹窗
    - 未选中任何卡片时禁用（灰色）
    - 逻辑说明：支持批量修改选中行的数量，班组，人员。使用平台的子表单实现批量修改，保存后对应修改的数值作用到对应的选中的卡片上，仅草稿状态的支持修改对应的数量，班组，人员。开立状态下仅支持修改班组，人员，其他状态不支持修改
2.  **\[开工\]** 按钮:
    - 蓝色主调
    - 点击对选中的派工单执行开工操作
    - 未选中任何卡片时禁用
    - 逻辑说明：
        - 开工保存时需要校验当前卡片的状态，状态若为“开立”则支持进行开工操作，若状态为草稿状态则提示先进行保存派工后在进行开工操作，其他状态不支持开工操作。
        - 开工后根据选择的班组和人员及数量生成对应派工单工序的开工操作记录，并修改当前工序组合单对应状态
        - 开工状态的不支持重复开工
        - 回写派工单工序的累计开工数量
        - 草稿状态不支持开工，需要进行提示
        - 页面没有清空的情况下，再次拖入新的派工单工序保存，若之前的工序组合单没有开工，则后续新加的派工单工序则加入到之前的工序组合单下
3.  **\[完工\]** 按钮:
    - 绿色主调
    - 点击对选中的派工单执行完工操作
    - 未选中任何卡片时禁用
    - 逻辑说明：
        - 完工保存时需要校验当前卡片的状态，状态若为“开工”则支持进行完工操作，若状态为草稿状态则提示先进行保存派工后在进行操作，其他状态不支持操作
        - 完工后根据选择的班组和人员及数量生成对应派工单工序的完工操作记录，并修改当前工序组合单对应状态，若当前工序工时的产生方式配置为时间差额，则完工时需自动生成对应的工时记录，
        - 完工状态的不支持重复完工
        - 完工是记录的完工批号为拼接而来，设备编码+设备位置+加工批次
        - 回写派工单工序的累计完工数量
        - 草稿状态不支持完工，需要进行提示
4.  **\[打印标签\]** 按钮:
    - 灰色中性
    - 点击打印选中派工单的标签
    - 未选中任何卡片时禁用
    - 打印标签内容待定，确定后补充
    - 草稿状态不支持完工，需要进行提示
5.  **\[保存派工\]** 按钮:
    - 灰色中性
    - 点击打印选中派工单的标签
    - 未选中任何卡片时禁用
    - 逻辑说明：
        - 点击保存派工时，仅状态为“草稿”的支持保存派工，其他状态皆不支持操作，并进行提示
        - 保存派工后根据对应的设备+日期为维度生成工序派工单+工序派工单明细，若选择多个设备的数据则需要进行拆分。
        - 初始生成对应的单据的状态为开立
        - 暂不考虑工序组合单的备料生成
        - 生产对应的工序组合单单，对应工序组合单明显中的批次号需要拼接存储：设备号+设备位置+批次号，示例：GL001-1-26051501
6.  **\[全选\]** 按钮:
    - 逻辑说明：
        - 全选当前页面的卡片信息，再次点击为全消

**交互**:

## 四、数据校验与错误提示

### 4.1 数量校验

**校验规则**: 排产数量不能超出上游工序的已完成数量

**错误提示**:

- 卡片红色边框 + 浅红背景
- 数量输入框红色边框 + 红色文字
- 显示错误提示文本："⚠ 超出上游工序可派工数量（最大 30 PCS）"

### 4.2 工序数量校验

**校验规则**: 上游工序无完工数量时，当前工序不能进行开工操作

**错误提示**:

- 空卡槽红色虚线边框
- 显示提示文本："⚠ 暂无可开工数量"

### 4.3 产能校验

**校验规则**: 排产数量不能超过设备剩余产能

**提示方式**:

- 设备产能进度条颜色变化：
    - 绿色：0-80%
    - 橙色：80-100%
    - 红色：>100%（超载）
- 超载时显示"超载 XX PCS"提示

## 五、拖拽交互详细流程

### 5.1 拖拽派工流程

1.  **开始拖拽**:
    - 鼠标按下左侧订单卡片
    - 光标变为"抓取"样式
    - 卡片半透明 + 微旋转
2.  **拖拽过程中**:
    - 实时检测右侧可放置区域（空卡槽）
    - 可放置的卡槽高亮绿色虚线边框
    - 不可放置的卡槽显示红色禁止图标
3.  **释放鼠标**:
    - 如果放置在合法区域：创建派工卡片，显示动画（绿色光晕）
    - 如果放置不合法：卡片飞回左侧列表，显示错误提示
4.  **完成派工后**:
    - 左侧订单卡片隐藏
    - 右侧对应位置显示派工卡片
    - 设备产能进度条更新
    - 显示 Toast 提示："派工成功"

### 5.2 拖拽调整排产流程

1.  **拖拽已分配的派工卡片**到同一设备的其他卡槽或日期
2.  **跨设备拖拽**: 支持将派工单从一个设备拖到另一个设备
3.  **拖拽排序**: 同一设备同一日期的派工卡片可拖拽排序

## 六、 测试用例建议

1.  **拖拽功能测试**: 测试各种拖拽场景（同设备、跨设备、跨日期等）
2.  **数据校验测试**: 测试数量超限、工序顺序错误等场景
3.  **性能测试**: 测试大量派工单时的页面响应速度
4.  **兼容性测试**: 测试不同浏览器、不同分辨率的显示效果
