## 计量单位

**【功能描述】**

计量单位模块用于定义和管理库存物料的计量单位，确保在采购、销售、库存管理等业务环节中使用统一的计量标准。通过此模块，可以配置不同物料的基本计量单位和辅助计量单位，便于进行数量转换和统计分析。

**【功能说明】**

- **业务菜单：**基础设置 -> 库存相关 -> 计量单位
- **业务按钮：**
    - 新建：创建新的计量单位。
    - 修改：编辑现有的计量单位信息。
    - 删除：删除不再使用的计量单位。
    - 数据同步：同步计量单位数据至CJC系统。
- 基础数据来源：企业内部标准、行业标准或政府规定的计量单位 基础数据用途：用于在系统中定义物料的计量单位，确保数据的一致性和准确性

## 工艺路线

【功能描述】 工艺路线模块用于定义产品从原料到成品的完整生产流程，确保各工序按指定顺序执行。通过此模块，可以配置产品需要经过的各道工序及其顺序，便于生产调度和流程优化。

【功能说明】

- **业务菜单**：生产管理 -> 基础档案 -> 工艺路线
- **业务按钮**：
    - 新建：创建新的工艺路线。
    - 修改：编辑现有的工艺路线信息。
    - 删除：删除不再使用的工艺路线。
    - 数据同步：同步工艺路线数据至CJC系统。
    - 分享：当前工艺路线下的工序信息支持分享其他工艺路线下，实现工艺路线的复用，分享者一旦被修改后被分享者一起变更
    - 版本变更：基于当前版本进行版本变更
    - 失效：将当前工艺路线进行失效，后续单据无法使用
    - 工序：工艺路线下的工序信息
        - 拉取：指定拉取对应工艺路线下的工序信息
        - 导入：支持导入子工序，设备参数，个性化配置
        - 子工序：对应工序下绑定的子工序
            - 设备参数：可对接设备参数，设定对接哪台设备哪个参数，需与IOT配合使用实现取数效果
            - 个性化配置：可配置个性化录入的参数，满足生产中不同业务录入的需求
        - 瑕疵：对应工序的次品分类信息，工序不一样配置可不一样
- **基础数据来源**：企业内部工艺设计文件、生产经验
- **基础数据用途**：用于定义产品生产的完整流程，确保生产活动的有序和高效

## 生产订单

**【功能描述】** 生产订单模块用于管理和跟踪生产任务的执行情况，确保产品按时、按质、按量完成。通过此模块，可以创建和维护生产订单，记录生产任务的详细信息，如产品、数量、计划开始和结束日期等，便于生产调度和进度跟踪。

【功能说明】

- **业务按钮**：
    - 生产订单维护
        - 可以手工创建生产订单
        - 可从ERP进行数据同步
        - 可以参照来源销售订单生成生产订单（暂未实现）
        - 可以查看、修改或删除生产订单
        - 可以提交、审核或弃审生产订单
    - 生产订单备料维护
        - 可以自动生成生产订单备料
        - 可从ERP进行数据同步
        - 可以查看生产订单备料
        - 可以维护生产订单备料的基本信息：
            - 新增、修改、删除生产订单备料
            - 维护备料的供应方式（包括发料方式、供应方式、供应地点等）
            - 维护备料的厂牌
    - 生产订单工序维护
        - 可以自动生成生产订单工序
        - 可以查看生产订单工序
        - 可从ERP进行数据同步
        - 可以新增、修改、删除生产订单工序（生产订单派工前）
        - 可以维护工序的基本信息和详细信息
        - 可以维护按照物料清单自动生成联副产品信息，也可手动维护
        - 可以维护与生产订单工序相关的备料
        - 可以维护与生产订单工序下的子工序信息和设备参数及个性化参数信息
        - 可以维护与生产订单工序下的瑕疵信息
        - 可以维护与生产订单的现场物料信息
    - 订单确认&批量订单确认：可按照工艺路线及物料清单重新加载当前生产订单下的数据包含备料，工序，子工序，设备参数，个性化参数，瑕疵信息，现场物料
    - 开工&完工：执行生产订单开工&执行生产订单完工
    - 领料申请：支持按照生产订单下的备料信息进行领料申请
    - 单批派工：支持选单个订单进行批量派工，填写不同的生产数量，生产批号，计划开完工时间等，生成派工单
        - 保存&保存并提交：提交操作中多一步派工单提交操作
    - 批量派工：支持选多单进行批量派工，填写对应的生产数量，生产批号，计划开完工时间等，生成派工单
        - 保存&保存并提交：提交操作中多一步派工单提交操作
    - 一键派工：按照生产订单信息进行全数量派工，无需填写信息，生成派工单

- **业务按钮**：
    - 开工：选择班组、人员、设备信息后进行开工操作，生成对应开工操作记录
    - 完工：选择班组、人员、设备，生产批号等信息后进行完工操作，生成完工操作记录
        - 最后一次完工：开启最后一次完工，标志当前工序生产完工，若为最后一道工序最后一次完工可生成对应的完工申报单
        - 联副产品报工：开启联副产品报工，输入数量后可进行联副产品报工
    - 暂停：生产过程中开工后，可进行暂停操作，暂停后生成对应停机记录。暂停后可重新开工
    - 联副产品：
        - 可针对当前工序新增联副产品信息，进行后续完工时联副产品报工
    - 后序：快捷跳转至下一道工序
    - 前序：快捷跳转至上一道工序
    - 返工：针对不良数量进行返工，可设定返工工序信息
    - 过程记录
        - 过程记录：可维护生产过程中的正常记录信息及异常记录信息
        - 次品记录：可维护当前工序产生的对应次品信息
    - 质检详情：可查看对应当前工序的报检单信息，包含首检，过程检及终检
    - 委外：将当前工序进行委外，可选定对应的供应商信息
    - 报检：可按照需求进行手动报检，支持首检及过程检类型进行报检，报检后生成工序报检单，在质检详情中体现对应报检单据信息
    - 操作记录：开工，完工操作产生，支持删除及修改
    - 用料情况：查看当前工序的用料情况
    - 工时：查看当前工序记录的工时记录信息
        - 新增工时：按照班组人员新增当前工序的工时记录
        - 工时分摊：按照班组人员，订单进行分摊，确认无误后进行保存，新增对应的工时记录
    - 报告：查询对应子工序的操作指标记录信息
    - 子工序：针对对应工序的子工序信息进行操作及查看
        - 未完工：当前页子工序可进行开工，完工，确认，复核操作，按照对应操作类型及数据配置进行显示
            - 录入：进行指标参数录入，生成对应子工序质量录入信息
            - 跳转下一个参数：点击快速跳转下一个录入的参数
            - 删除：已录入的参数信息支持删除
        - 已完工：当前页子工序为已完工信息
        - 全部：全部子工序信息
        - 明细信息：查看对应子工序录入的指标值明细信息列表

- 支持场景2：同料，一个批号，理货后换成出两个批号(确保数量一致)
- （先不处理）支持场景3：同料，两个或两个以上的批号，理货后换成一个，或多个批号出（确保数量一致）
