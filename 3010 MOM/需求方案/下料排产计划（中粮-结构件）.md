# 下料排产计划（中粮-结构件）

## 一、产品概述

### 1.1 业务背景

「下料排产」是才匠智能制造系统的核心生产排程模块，面向生产计划员和车间调度人员，用于在 PC 端对下料工序的**派工单**进行组合排产、下发执行及用料管控。系统通过最优套料算法将多个派工单自动组合为"组合单"，最大化材料利用率，同时支持手动组合、追加、确认等操作。

### 1.2 核心功能清单

| #   | 功能模块 | 描述  |
| --- | --- | --- |
| 1   | 系统头部 | 品牌标识 + 公司名 + 用户信息 + 操作图标 |
| 2   | 标签栏导航 | 多标签切换，支持关闭标签 |
| 3   | 顶部筛选项 | 计划日期（从/至）+ 优先级筛选 |
| 4   | 待排生产订单表 | 左侧面板，勾选订单后联动右侧加载派工工序 |
| 5   | 派工单工序表 | 右侧面板，勾选工序后可批量排产 |
| 6   | 排产组合结果表 | 下半部分主区域，Tab 切换「组合单」/「明细」，支持开工/完工/确认等操作 |
| 7   | 用料分析 | 下半右侧，显示选中组合的原料信息、用量填写与出材率分析 |
| 8   | 组合单创建弹窗 | 两步创建：预览选中工序 → 规格校验（不一致禁止创建） |
| 9   | 追加到已有组合弹窗 | 两步追加：先选目标组合，再选要追加的派工工序 |
| 10  | 批量确认弹窗 | 多选组合卡，实时汇总件数与工时 |
| 11  | 列宽可拖动 | 上下两个分割条，左右两列宽度可拖拽调整 |
| 12  | 分页  | 每页显示切换、跳转、仅选中项筛选 |
| 13  | 导出排产单 | 导出 Excel/CSV 格式 |
| 14  | 开工/完工/打印标签 | 批量操作功能 |
| 15  | Toast 反馈 | 操作成功/失败/警告提示，居中显示 |

### 1.3 核心业务流程

```
生产订单勾选
    ↓ 联动
派工单工序加载（仅显示被选中订单关联的工序）
    ↓ 勾选工序
创建组合单（系统校验：同设备 + 同规格 + 同材质方可组合）
    ↓ 创建成功
排产组合结果展示（含利用率计算）
    ↓ 批量确认
下发到车间执行
    ↓ 执行后
记录用料情况（标准用量 vs 实际用量）
```

![](files/019e1ad1-cdb8-7917-ae78-ff11a6f100a2/a00f2e78-88d8-4c61-acd3-3a5e88ce0fac.png)

追加：

- 追加到勾选的工序组合单下，若勾选多个则提示仅支持追加到指定组合单，若为勾选进行追加则需要进行提示，

- 追加时也需要满足原材料一致的才能支持追加，否则不支持
- 追加时只能追加进待确认的工序组合单，否则需要给出提示

### 5.6 利用率进度条

- 样式：`border: 1px solid [颜色]` + 左侧进度填充 + 右侧透明背景

| 利用率 | 颜色  | 调色类 |
| --- | --- | --- |

- 进度条内文字居中显示百分比

    - 已确认状态的支持操作开工，支持多选进行开工根据所选项匹配对应的工序组合工单明细，进行开工，生成对应的开工操作记录，记录对应的开工时间，设备及其他信息则为当前排产时做选择的信息进行存储至开工记录中
    - 开工时需校验当前工序是否支持开工，例如是否还有开工数量剩余等，参照平板端开工时的校验同步实现
    - 兼容工序报检相关功能
- 完工：
    - 已确认状态的支持操作完工，支持多选进行完工根据所选项匹配对应的工序组合工单明细，进行完工，生成对应的完工操作记录，记录对应的完工时间，设备及其他信息则为当前排产时做选择的信息进行存储至完工记录中，按照对应工序配置的工时生成方式如果为时间差额，则需要自动生成对应的工时记录，工时为完工时间-开工时间
    - 完工时需校验当前工序是否支持完工，例如是否还有完工数量剩余等，参照平板端完工时的校验同步实现
- 全部确认：
    - 待确认状态的支持进行确认操作，已确认的不支持重复确认，已确认状态的不支持进行追加
    - 支持进项批量确认
- 打印标签：
    - 打印对应的组合单标签
- 导出
    - 使用平台标准的导出功能

## 六、用料分析面板（区域四）

### 6.1 物料 Hero 区域

### 6.2 用量填写区域（左侧）

数据加载逻辑：点击左侧的工序组合单，显示对应组合单下的备料信息及标准用量信息

**字段网格（2 列布局）**：

| 字段  | 类型  | 样式  |
| --- | --- | --- |
| 标准用量 | 只读计算值 | 蓝色大字 18px 加粗，标注「系统计算」 |
| 实际用量 | 只读计算值 | 灰色/橙色大字 18px，标注「上料量 − 余料」 |
| 上料量 | 可编辑输入 | 18px 加粗输入框，单位 kg，橙色数字 |
| 余料  | 可编辑输入 | 18px 加粗输入框，单位 kg，橙色数字 |
| 备注  | Textarea | 可填写备注信息 |
| 附件  | 上传按钮 | 虚线框，点击上传文件 |

**实际用量计算逻辑**：

```
实际用量 = 上料量 − 余料
```

- 上料量和余料均有 `oninput="updateActualUsage()"` 联动
- 两个字段均有值时，实际用量显示橙色；任一为空时显示灰色「—」
- 实际用量同步计算并显示在用料分析卡片中

### 6.3 出材率 / 利用率分析（右侧）

> ⚠️ **注意**：当前原型中右侧区域为空白占位（高度 0），本节描述为完整设计意图。

**出材率**：

- 进度条：绿色填充（出材部分）+ 橙色填充（余料部分）
- 标签：出材率数值（大号加粗绿色）/ 余料率（大号加粗橙色）

**利用率**：

- 进度条：单一颜色进度条 + 百分比文字
- 配色规则同组合单表格中的利用率进度条

### 6.4 保存操作

| 按钮  | 行为  |
| --- | --- |
| 保存用料信息 | 点击后显示 Toast「用料情况已保存」success 类型 |

- 保存用料信息
    - 当前工序组合单下对应的实际发料日已存在数据则显示对应的数据信息，且不支持修改，则当前状态不支持操作
    - 保存时将对应的上料量及余量，备注及附件，实际发料日回写至对应的工序组合单备料信息，已保存的不支持重复保存
    - 需要根据对应实际用量进行分摊，分摊至当前工序组合单对应的派工单下，生产对应一单初始状态的领料单，明细记录来源不同
        - 分摊逻辑：派工单备料标准用量 / 派工单派工数量 \* 实际用量 = 当前派工单对应领料的领料数量
    - 对应领料单删除时，需要校验如果来源为工序组合单需要回写对应的工序组合单实际用量等信息，以便于重新生成

## 八、边界情况处理

| 场景  | 处理方式 |
| --- | --- |
| 创建组合时规格不一致 | 橙色警告区列出所有不一致项，红色错误文字，确认按钮 disabled |
| 追加组合时未选择目标 | 确认按钮 disabled，「第二步」不展开 |

| 上料量未填写 | 实际用量显示灰色「—」 |
| 余料未填写 | 实际用量 = 上料量（scrap = 0） |
| 上料量 < 余料 | 实际用量显示为负数（允许，用于校验提示） |
| 组合单表格为空 | 显示空态表格（表头保留，内容行显示「暂无数据」） |
| 工序明细 Tab 无选中组合 | 横幅显示「请先选择组合」 |
| 每页条数选择变化 | 自动回到第 1 页，重新渲染表格 |
| 跳转页码超出范围 | 自动截断到有效范围 |
| 拖动列宽超出限制 | 限制在 20%~80%，超出后停止 |
