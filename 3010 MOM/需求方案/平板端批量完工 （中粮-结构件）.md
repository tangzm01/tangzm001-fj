# 平板端批量完工 （中粮-结构件）

## **一、产品背景与目标**

**业务场景：** 生产车间工人/班组长使用平板，对派工单下的多道工序进行批量开工、报工（完工）操作。

**核心价值：** 减少逐条操作，提升车间报工效率；支持部分数量开工/完工，应对实际生产中分批完成的实际情况。

---

## **二、数据模型**

### **2.1 核心实体**

| **实体** | **字段** | **说明** |
| --- | --- | --- |
| **订单（派工单）** | 项目号(PJ)、派工单号(PGD)、生产工单(MO)、品名、规格、计划完工日期、订单总量、工序订单量 | 顶层级，展示用 |
| **工序（Process/Step）** | 工序号、工序名称、类型(标准/返工/委外)、计划数量、已开工数量、已完工数量、良品数量、实际开工时间、状态 | 核心操作对象 |
| **工序状态** | `done` 已完工 / `doing` 进行中 / `wait` 待报工 / `pending` 待开工 | 由数量关系计算得出 |
| **资源** | 设备、班组、工作中心、计划开工日期、作业人员 | 工序粒度 |

### **2.2 工序类型枚举**

| **类型** | **值** | **原型颜色** |
| --- | --- | --- |
| 标准工序 | `std` | 绿色 `#1A835C` |
| 返工工序 | `rew` | 橙色 `#E17516` |
| 委外工序 | `out` | 紫色 `#9333EA` |

## **四、批量操作视图 — 功能详述**

### 4.1 视图切换 Tab

**两个 Tab 页签：**

1.  **批量操作**（默认选中）：显示订单卡片列表，支持勾选工序批量操作
2.  **工序明细**：显示所有工序的横向滚动表格，适合逐条查看和编辑

**右侧附加控件（与 Tab 同一行）：**

#### ① 工艺路线开关（Toggle Switch）

- **位置：** Tab 行最右侧
- **标签：** 「显示全部工艺路线」
- **默认状态：** 关闭（OFF）
- **交互：**
    - 关闭 → 所有订单卡片的「工艺流程」区域折叠隐藏（只显示订单信息或显示符合条件查询工序信息）
    - 打开 → 所有订单卡片的「工艺流程」区域展开（显示工序卡片流）
- **使用场景：** 用户想快速浏览订单概览时关闭；需要查看具体工序时打开

#### ② 状态筛选 Chips（色块按钮组）

- **位置：** Tab 行右侧，工艺路线开关左侧
- **组成：** 5 个可多选的色块按钮
- **按钮列表：**

| 按钮文字 | 对应状态 | 使用场景 |
| --- | --- | --- |
| 等前序（前道工序未完工） | 前序工序未完成，当前工序不能开始 | 过滤出被阻塞的工序 |
| 待执行（开立） | 前序已完成，当前工序可以开始 | 过滤出可开工的工序 |
| 生产中（开工） | 正在执行的工序 | 查看进行中的工序 |
| 异常暂停（暂停） | 因异常而暂停的工序 | 处理异常工序 |
| 已完工（完工） | 已完成全部报工的工序 | 查看历史完工工序 |

### **4.2 筛选区**

**筛选项（5项 + 2按钮）：**

| **字段** | **控件类型** | **说明** |
| --- | --- | --- |
| 生产订单 | 文本输入 | 精确/模糊搜索，点筛选触发 |
| 派工单号 | 文本输入 | 精确/模糊搜索，点筛选触发 |
| 料号  | 文本输入 | 精确/模糊搜索，点筛选触发 |
| 品名  | 文本输入 | 精确/模糊搜索，点筛选触发 |
| 工序号 | 文本输入 | 精确/模糊搜索，点筛选触发 |
| 工序名称 | 文本输入 | 精确/模糊搜索，点筛选触发 |
| 筛选  | 按钮  | 符合条件则展示，否则显示空态 |
| 重置  | 按钮  | 清空所有筛选项，恢复全量展示 |

**筛选逻辑：** 订单卡片显示条件 = 订单维度满足以下任一条件：

- 生产订单，派工单号包含关键词
- 料号，品名包含关键词
- 该订单存在工序名称匹配，且仅显示该工序
- 该订单存在工序编码匹配，且仅显示该工序

筛选为空时显示空态占位图（搜索图标 + “没有符合条件的订单” + 清空筛选按钮）。

### **4.3 批量操作工具栏**

**位置：** 固定在视图底部居中，z-index 最高，始终可见

**工具栏内容：**

**① 全选组合控件**

- Checkbox + “全选” 文字 + 下拉箭头
- 全选状态根据已勾选工序数量变化：
    - 0个 → 白色普通态
    - 全部选中 → `is-selected` 态（绿色边框+背景）
    - 部分选中 → `is-mixed` 态

**② 批量操作按钮组（3个）**

| **按钮** | **样式** | **触发逻辑** | **前置条件** |
| --- | --- | --- | --- |
| 快速完工 | 绿色  | `batchAction('start')` | 已选 ≥1 个「待开工」工序 |
| 快速报工 | 蓝色  | `batchAction('report')` | 已选 ≥1 个「待报工/进行中」工序，并且所选工序的时是否开工操作为否，可进行快速报工 |
| 部分完工 | 橙色  | `openPartialModal('done')` | 已选 ≥1 个工序 |

> ⚠️ **规则：** 已完成的工序（`done` 态）不可选、不可操作，工具栏自动排除。

**快读完工**

- 支持批量操作页多选工序进行快速完工，支持工序明细页多选工序进行快速完工
- 完工时需要校验的信息参考对应平板端正常完工功能，例如数据的必填项，完工数量的校验，以及后续生产的单据信息
- 支持多选进行完工根据所选项匹配对应的派工单工序，进行完工，生成对应的完工操作记录，记录对应的完工时间，设备及其他信息则为当前工序所选择的信息进行存储至完工记录中，按照对应工序配置的工时生成方式如果为时间差额，则需要自动生成对应的工时记录，工时为完工时间-开工时间

**③ 批量计数气泡**

- 全选按钮右侧显示已选数量（如 `12`）
- 实时更新

## **十一、核心业务规则汇总**

### **11.1 工序操作约束**

| **操作** | **允许状态** | **禁止状态** |
| --- | --- | --- |
| 开工  | wait / pending | done |
| 报工（完工） | wait / doing | done |
| 部分开工 | wait / pending（需填数量） | done |
| 部分完工 | doing / wait（需填数量） | done |
| 查看详情 | 所有状态 | 无   |

### **11.2 数量边界校验**

```
0 ≤ 已完工数量 ≤ 已开工数量 ≤ 计划数量
已完工数量（本次）≤ 已开工数量（本次）≤ 计划数量（本次）
```

### **11.3 并行工序处理**

一个派工单内可能存在并行工序（如同一步骤的多个分支）：

- 开工/完工状态独立计算，互不影响
- 批量操作时需逐工序校验，不是按派工单批量处理

### **11.4 工序类型对操作的影响**

- **标准工序**：正常开工/报工流程
- **返工工序**：同上，但数量从剩余待返工数量开始计算
- **委外工序**：开工即标记「已发外协」，完工由接收确认触发

| `PUT /api/processes/{id}` | PUT | 更新单条工序（含数量、人员、资源） |
| `POST /api/processes/batch-report` | POST | 批量报工（数组 of {id}） |
| `POST /api/processes/partial-done` | POST | 部分完工（数组 of {id, qty}） |
| `GET /api/persons` | GET | 获取作业人员列表（弹窗选择用） |
