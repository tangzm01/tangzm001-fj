# 移动端-扫码开完工

# 一、产品概述

## 1.1 业务背景

在服装/纺织/制造等行业中，产品（胚布/裁片/半成品）需要经过多道工序流转，过程中产品装在特定容器（工装器具）中运输和暂存。工序开工/完工是生产管理的核心节点，工人需要通过扫码快速完成工序的开始和结束操作，并实时记录容器与工序的关联数据。

## 1.2 系统目标

为车间工人提供手机端扫码批量开工/完工工具，实现：

• 快速扫码识别容器和产品批次信息

• 批量选择容器进行开工或完工操作

• 实时查看工序进度和容器状态

• 与派工单（生产工单）联动，记录实际作业数据

## 1.3 核心价值

相比传统手工纸质记录，系统带来以下核心价值：

|     |     |
| --- | --- |
| **效率提升** | 扫码代替手工输入，开工/完工操作从分钟级降至秒级 |
| **数据准确** | 扫码自动关联容器、批次、工序，杜绝人工抄写出错 |
| **实时可见** | 开工/完工数据实时回传，管理人员随时掌握车间进度 |
| **批量操作** | 支持一次性选择多个容器批量开工/完工，减少重复操作 |
| **质量追溯** | 每步操作记录时间戳和操作人，支持全流程质量追溯 |

# 二、数据模型

## 2.1 核心实体

|     |     |     |
| --- | --- | --- |
| **实体名称** | **核心字段** | **说明** |
| **容器 / Container** | 工装器具编号 + 归属车间 + 件数上限 + 当前件数 | 存放产品的物理载体，如52号筐、53号筐等 |
| **组合单 / Combo** | 组合单号 + 产品名称 + 款号 + 数量 + 目标工序 + 状态 | 将多道工序打包为一个组合的生产单据 |
| **工序卡片 / Process** | 工序名称 + 类型编码 + 状态 + 所属组合单 | 组合单内的单道工序实例 |
| **派工单 / Dispatch** | 派工单号 + 关联组合单 + 工序 + 执行人 + 计划量 | 将工序指派给具体执行人的调度单据 |
| **工序类型枚举** | std（标准工序）/ rew（返工工序）/ out（外发工序） | 工序的分类标识，影响流程分支 |

## 2.2 工序类型

工序按类型分为三种，每种有独立的颜色标识和流程：

|     |     |     |     |
| --- | --- | --- | --- |
| **类型编码** | **类型名称** | **颜色标识** | **说明** |
| **std** | 标准工序 | 006B3C | 正常生产流转，标准流程 |
| **rew** | 返工工序 | D97706 | 产品返修/返工，需专项记录原因 |
| **out** | 外发工序 | 7C3AED | 委托外部加工，返回后记录外发结果 |

# 三、页面结构

系统由三个主页面组成，通过底部 Tab 导航切换：

|     |     |     |
| --- | --- | --- |
| **页面名称** | **位置** | **核心功能** |
| **容器列表页** | 首页/默认页 | 查看所有容器及其状态，支持扫码入口 |
| **组合单列表页** | 第二个 Tab | 按组合单维度管理工序进度，支持状态筛选 |
| **扫码工作台** | 第三个 Tab | 核心操作页：开工 / 完工 / 扫码交互 |

# 四、详细功能说明

## 4.1 容器列表页

### 4.1.1 功能概述

容器列表页是系统的默认首页，展示车间内所有容器及其关联工序的整体状态。工人可在此页面快速了解哪些容器待处理、哪些已完成，并通过扫码快速进入扫码工作台。

### 4.1.2 视图模式切换

页面支持两种视图模式，通过右上角切换按钮控制：

**列表视图：**每行一个容器，显示编号、车间、件数、当前工序名称等关键信息，适合浏览大量容器。

**网格视图：**以卡片形式展示容器，每卡片显示编号、状态指示灯、件数占比，适合快速扫视状态。

### 4.1.3 容器卡片信息

单个容器卡片的完整信息展示：

|     |     |
| --- | --- |
| **字段** | **说明** |
| **容器编号** | 工装器具编号，如"52号"、"53号"，醒目显示 |
| **归属车间** | 该容器所属车间的名称 |
| **件数信息** | 格式"5/10件"，表示当前件数/容量上限 |
| **当前工序** | 该容器关联的当前执行工序名称 |
| **工序类型** | 颜色标签：绿色(std) / 橙色(rew) / 紫色(out) |
| **状态指示** | 卡片边框颜色表示状态（灰/黄/绿/蓝） |
| **操作入口** | 点击卡片进入该容器关联的扫码工作台 |

### 4.1.4 状态筛选

顶部提供快捷筛选栏，点击即可过滤指定状态的容器，支持多选：

|     |     |
| --- | --- |
| **筛选标签** | **含义** |
| **全部** | 显示所有容器（默认选中） |
| **待开工** | 工序状态为 pending（灰色），尚未开工 |
| **进行中** | 工序状态为 doing（黄色），正在执行 |
| **待完工** | 工序状态为 wait（蓝色），等待完工确认 |
| **已完成** | 工序状态为 done（绿色），全部工序已完成 |

### **4.1.5 扫码入口**

页面右上角提供扫码按钮，点击后调用手机摄像头扫描容器条码/二维码，扫描成功后自动跳转到对应的扫码工作台页面，并预填容器信息。

## 4.2 组合单列表页

### 4.2.1 功能概述

组合单列表页以"组合单"为主线，展示每张组合单下的所有工序及其进度。适合主管或组长从订单维度把控整体生产进度，快速定位某个组合单的瓶颈工序。

### 4.2.2 组合单卡片

每个组合单卡片展示以下信息：

|     |     |
| --- | --- |
| **字段** | **说明** |
| **组合单号** | 唯一标识，如"CB20240616001" |
| **产品名称** | 该组合单对应的产品/胚布名称 |
| **款号** | 产品款式编号 |
| **数量** | 该组合单的总件数 |
| **目标工序** | 当前正在或即将执行的目标工序 |
| **工序列表** | 展开后显示该组合单下的所有工序卡片 |
| **进度指示** | 卡片顶部或侧边显示整体完成百分比 |

### 4.2.3 工序卡片（组合单内）

展开组合单后，显示该组合单下的所有工序卡片：

|     |     |
| --- | --- |
| **字段** | **说明** |
| **工序编号** | 自动生成的序号（01、02、03...） |
| **工序名称** | 标准/返工/外发工序名称 |
| **工序类型** | 颜色标签（std=绿 / rew=橙 / out=紫） |
| **状态** | pending / doing / wait / done 四种状态 |
| **容器信息** | 关联的容器编号和当前件数 |
| **操作按钮** | 进行中显示"完工"按钮，待开工显示"开工"按钮 |

### 4.2.4 状态筛选

同容器列表页，提供四种状态快捷筛选，支持多选组合过滤。

## 4.3 扫码工作台（核心页面）

### 4.3.1 功能概述

扫码工作台是系统的核心操作页面，集成了开工、完工、扫码三大功能。工人通过 Tab 切换选择当前操作模式，在工作台上完成所有日常作业。

### 4.3.2 开工操作

点击底部"开工"Tab，进入开工模式，流程如下：

1\. 扫码或手动输入容器编号，识别目标容器

2\. 系统自动展示该容器关联的组合单和工序列表

3\. 工人选择本次要开工的工序（勾选框），可多选

4\. 选择派工单（若有多个派工单，通过弹层选择）

5\. 点击底部"批量开工"按钮，确认操作

6\. 系统记录开工时间戳、工序状态变为 doing，并显示成功提示

### 4.3.3 完工操作

点击底部"完工"Tab，进入完工模式，流程如下：

1\. 扫码或手动输入容器编号，识别目标容器

2\. 系统展示该容器下状态为 doing 或 wait 的工序列表

3\. 选择本次要完工的工序（勾选框），可多选

4\. 点击底部"批量完工"按钮，确认操作

5\. 系统记录完工时间戳、工序状态变为 done，并显示成功提示

### 4.3.4 扫码交互

扫码是本系统最高频的操作，交互规则如下：

|     |     |
| --- | --- |
| **场景** | **处理方式** |
| **扫码触发** | 点击页面顶部扫码图标或扫码输入框，调用手机摄像头 |
| **条码格式** | 支持一维码（Code128/EAN）和二维码（QR Code） |
| **识别内容** | 扫码结果为容器编号，匹配后自动查询并展示关联工序 |
| **扫码失败** | 显示"未识别到有效容器编号，请重试"提示 |
| **无关联数据** | 扫码识别了容器但无关联工序时，提示"该容器暂无关联工序" |
| **扫码弹窗** | 扫码时弹出全屏相机视图，扫描成功后自动关闭 |

### 4.3.5 派工单联动

派工单（Dispatch）是系统与 MES/ERP 的中间层数据，每张派工单关联一个工序。开工/完工时需选择对应的派工单：

**单张派工单：**自动选中，无需操作

**多张派工单：**弹出派工单选择列表（弹层），显示派工单号、执行人、计划量，完成选择后关闭弹层

**无派工单：**允许直接开工/完工，跳过派工单选择步骤

### 4.3.6 派工单弹层（全屏）

当存在多张派工单时，点击派工单区域弹出全屏弹层：

|     |     |
| --- | --- |
| **要素** | **说明** |
| **弹层内容** | 以列表形式展示所有可用派工单 |
| **每条信息** | 派工单号 + 执行人姓名 + 计划数量 + 当前进度 |
| **选择方式** | 点击某条派工单即选中，弹层自动关闭 |
| **关闭方式** | 点击左上角关闭按钮，或点击遮罩区域关闭 |
| **筛选逻辑** | 仅显示与当前工序和容器关联的派工单 |

# 五、数据校验规则

为保障数据准确性和系统稳定性，以下校验规则在操作执行前必须全部通过。校验失败时阻止操作并显示具体错误信息。

## 5.1 扫码输入校验

|     |     |     |     |
| --- | --- | --- | --- |
| **校验项** | **校验规则** | **失败提示** | **适用场景** |
| **非空校验** | 扫码或手动输入的容器编号不能为空 | 提示"请扫码或输入容器编号" | 开工 / 完工 |
| **格式校验** | 容器编号必须为数字（允许前缀字母，如"52号"提取52） | 提示"容器编号格式不正确" | 开工 / 完工 |
| **存在性校验** | 容器编号必须在系统中存在 | 提示"未找到该容器，请确认编号是否正确" | 开工 / 完工 |
| **长度限制** | 容器编号最大20个字符 | 提示"容器编号过长" | 手动输入 |

## 5.2 开工前置条件校验

|     |     |     |     |
| --- | --- | --- | --- |
| **校验项** | **校验规则** | **失败提示** | **优先级** |
| **工序选择** | 必须至少勾选一个工序才能开工 | 提示"请至少选择一个工序" | 开工  |
| **状态校验** | 所选工序的状态必须为 pending（待开工） | 提示"所选工序当前状态不允许开工" | 开工  |
| **重复开工** | 同一工序在同一容器上不能重复开工（状态doing不允许再次开工） | 提示"该工序已在进行中，请勿重复开工" | 开工  |
| **容器状态** | 容器当前件数必须大于0 | 提示"容器当前件数为0，无法开工" | 开工  |
| **派工单校验** | 若存在派工单数据，所选工序必须关联有效派工单 | 提示"该工序缺少派工单信息，请联系管理人员" | 开工  |
| **工序类型** | 返工工序（rew）开工时，系统记录返工原因字段 | 提示"请填写返工原因" | 开工（rew专用） |

## 5.3 完工前置条件校验

|     |     |     |     |
| --- | --- | --- | --- |
| **校验项** | **校验规则** | **失败提示** | **优先级** |
| **工序选择** | 必须至少勾选一个工序才能完工 | 提示"请至少选择一个工序" | 完工  |
| **状态校验** | 所选工序的状态必须为 doing（进行中）或 wait（待完工） | 提示"所选工序当前状态不允许完工" | 完工  |
| **件数校验** | 完工工序关联的容器当前件数必须大于0 | 提示"容器件数为0，无需完工" | 完工  |
| **完工数量** | 完工件数不超过容器当前件数 | 提示"完工件数不能超过容器当前件数" | 完工  |
| **完工数量** | 完工件数不超过派工单剩余计划量 | 提示"完工件数超出派工单剩余计划量" | 完工  |
| **完工时间** | 完工时间必须不早于该工序的开工时间 | 提示"完工时间不能早于开工时间" | 完工  |
| **外发工序** | 外发工序（out）完工时，需填写外发结果（如：良品数/不良数） | 提示"请填写外发工序的完工结果" | 完工（out专用） |

## 5.4 容器容量校验

|     |     |     |
| --- | --- | --- |
| **校验项** | **校验规则** | **失败提示** |
| **容量上限** | 容器当前件数（开工后增量）不能超过容器容量上限 | 提示"容器已满，无法继续开工" |
| **件数一致性** | 同一容器在多道工序间流转时，总件数保持不变（除非拆分/合并业务场景） | 提示"容器件数不一致，请联系管理人员处理" |
| **最小件数** | 容器当前件数不能为负数 | 提示"数据异常：容器件数为负数" |

## 5.5 工序状态流转校验

工序状态必须按照规定的方向流转，不允许跨状态跳跃：

|     |     |     |     |
| --- | --- | --- | --- |
| **状态值** | **状态名** | **可跳转至** | **说明** |
| **pending** | 待开工 | doing | 开工后 → 进行中 |
| **doing** | 进行中 | wait / done | 完工确认后 → 待完工 或 直接完成 |
| **wait** | 待完工 | done | 最终完工确认后 → 已完成 |
| **done** | 已完成 | （不可逆） | 最终状态，不允许回退 |

非法流转示例（系统应拒绝以下操作）：

**pending → done：** 跳过开工直接完工（违规）

**done → doing：** 已完成工序回退到进行中（违规）

**wait → doing：** 待完工状态回退到进行中（违规）

## 5.6 数据一致性校验

|     |     |     |
| --- | --- | --- |
| **校验项** | **校验规则** | **失败提示** |
| **工序-容器一致性** | 每条工序记录必须关联有效的容器ID，容器被删除时该工序不可操作 | 提示"关联容器数据异常，请联系管理人员" |
| **工序-组合单一致性** | 每条工序必须属于一个有效的组合单，组合单状态为"已取消"时工序不可开工 | 提示"该组合单已取消，无法进行操作" |
| **派工单-工序一致性** | 派工单关联的工序ID必须真实存在，工序被删除时派工单失效 | 提示"派工单关联工序已失效" |
| **件数合计校验** | 完工件数合计应不超过开工时的件数（允许损耗率范围内的合理减少） | 提示"完工件数与开工件数差异超出允许范围" |
| **时间戳逻辑** | 同一工序：开工时间 ≤ 完工时间；同一容器多工序：前工序完工时间 ≤ 后工序开工时间 | 提示"时间戳逻辑错误，请检查数据" |

# 六、状态流转

## 6.1 工序四态定义

|     |     |     |     |     |
| --- | --- | --- | --- | --- |
| **状态值** | **状态名** | **颜色** | **指示灯** | **说明** |
| **pending** | 待开工 | 9CA3AF | 灰色  | 工序已创建，等待工人扫码开工 |
| **doing** | 进行中 | F59E0B | 黄色  | 工序已开工，正在执行中 |
| **wait** | 待完工 | 3B82F6 | 蓝色  | 执行完成，等待完工确认 |
| **done** | 已完成 | 10B981 | 绿色  | 完工确认，工序完结 |

## 6.2 完整状态流转图

工序在生命周期内按以下路径流转：

**pending（待开工）**  ──开工操作──>  **doing（进行中）**  ──完工确认──>  **wait（待完工）**  ──最终确认──>  **done（已完成）**

注：doing 可直接跳转到 done（无需经过 wait），适用于短周期工序。
